# 方向初稿共用素材

这是多文件离线演示包。请保留整个 `design-demos` 目录，不单独移动内部 slide；所有字体与标志保存在本目录，不依赖演示时联网。

## 真实品牌资产

- `gold-band.svg`：仓库 `web/public/logo.svg`，README 与官网采用的真实三色交织带标志。原色，不重新绘制或变形。
- `claude-code.svg`：Simple Icons 分发的 Claude Code 标志，https://cdn.simpleicons.org/claudecode 。官方产品身份核对：https://claude.com/product/claude-code 。这是图标库副本，不声称为独立官方 press kit。
- `kubernetes.svg`：CNCF 官方 artwork，https://raw.githubusercontent.com/cncf/artwork/main/projects/kubernetes/icon/color/kubernetes-icon-color.svg 。用途仅标识测试任务，不暗示背书或认证。使用政策：https://github.com/cncf/artwork 。

## 字体

- `inter-latin-variable.woff2`：从项目 `themes/gold-band/assets/fonts/` 复制，Inter Variable，OFL-1.1。
- `misans-vf.woff2`：从同一目录复制，Gold Band MiSans，Apache-2.0。
- `LICENSES.json`：来自 `themes/gold-band/LICENSES.json`，原样保留声明。
- 字体选择继承项目真实字体体系；这次是品牌规范内使用 Inter，不是另选默认 display 字体。数字与中文按字体覆盖分工。
