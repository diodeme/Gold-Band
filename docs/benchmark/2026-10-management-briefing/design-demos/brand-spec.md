## Logo

- 主标志：`assets/gold-band.svg`，复制自 `web/public/logo.svg`，已对照桌面 PNG 检查真实形状。
- 不再使用上一版的几何金环；真实标志是红、蓝、橙三色交织带。
- Claude Code：`assets/claude-code.svg`，Simple Icons 品牌副本，橙色像素形标志；与名称并列用于对照身份。

- 可内嵌 SVG 或以 base64 图片嵌入；多文件离线包也可引用这些本地素材。字体与素材目录整体随 deck 分发。

金色与品牌原色不承担所有数据序列区分。数字文字使用前景色；需要强调时可通过字重、面积或局部底色。禁止用任意上升曲线表示尚未完成的趋势。

## 字体

- `assets/inter-latin-variable.woff2`：Inter Variable，项目实际西文与数字字体。
- `assets/misans-vf.woff2`：Gold Band MiSans，项目中文字体。
- 共用 `assets/fonts.css`；字体完全本地化。Inter 用于 display 属于继承项目品牌字体的明确例外。
- MiSans 已配置的可靠字重为 250–520，中文标题用 500–520，靠字号与构图而非浏览器伪粗来制造层级。
- 1920×1080 原始画布：主标题 84–124px，正文 28–36px，注释至少 20px（缩到 1280 后仍可读）。hero 数字 180–280px。
- 中文字距 -0.02em 至 0；`text-wrap: pretty` / `balance`；不能用极细小字制造高级感。

## 图片、UI 与动效判断

本次是意图 / 数据汇报，不是产品界面演示。移除产品 UI 截图不会损失这两页的论证，因此不加 UI 或 stock 照片。共享三枚真实 logo 已足够完成身份识别。

没有影片、背景音乐、水印或复杂持续动画。视觉母题必须源自「单一工作流变成受控分工，再收敛到验收」，而非装饰性发光线条。
