# 内置提示词编写规则

本文件是 `src/prompts/` 下内置提示词正文编写的详细规则真源。提示词的存放位置、语言目录和 system/user 划分见 `AGENTS.md`。

## 1. 描述能力，不绑定特定 Agent 的工具

- 内置提示词会发给不同的 ACP Agent，正文应描述需要的能力（如类型检查、任务跟踪、结构化提问），不写死某个 Agent 独有的工具名。
- 确实需要点名工具时，写成“如有 X 或等价工具则使用，否则……”，并给出没有该工具时的做法。

验收：提示词中出现的每个工具名都带有可用性条件和替代路径。

## 2. 规则合并为单一定义

- 修改提示词时，把新约束并入已有定义，不在原文后追加补充句；同一规则在同一文件内只保留一处表述。
- 发现两处表述冲突时，先确定正确语义再统一改写，不叠加例外句修补。
- 各语言目录同步修改后保持相同的语义和结构。

验收：同一文件内不存在重复或互相矛盾的规则表述；七种语言的对应文件改动一致。
