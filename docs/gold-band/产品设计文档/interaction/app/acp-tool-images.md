# ACP 工具返回图片

## 识别与归属

- `toolCall/toolCallUpdate` 先识别标准 `content[i]`（外层 `type=content`，内层 `content.type=image`）。仅当标准位置没有图片块时，识别 `rawOutput.result.content[i].type=image`；不按 Agent 名称分支，不递归猜测 JSON，不合并两个来源。标准图片损坏时局部报错，不切换来源。
- 图片归属原工具调用。工具详情展开时可见缩略图；所属过程段结束后，在过程栏外、紧接过程栏下方显示同一批图片，先于本轮附件和 diff 变更卡片及后续助手正文，不等待整个 Turn 结束，不自动展开过程栏，不合成为助手消息或文件产物。
- 缩略栏复用已发送图片的 72px 缩略控件和右键菜单，单排横向滚动、不换行，滚动条仅悬浮时显示。点击进入现有工作区图片 Tab；复制与另存为按需读取原图，不保存缩略图。
- 滚动条复用共享 shadcn ScrollArea 主题尺寸：横向滑块的最小长度作用于宽度，竖向作用于高度；横向厚度由轨道宽度 token 与内缩决定，不能被竖向最小长度撑大。

## 存储与接口

- 过程列表只返回工具身份、名称、状态和简要参数，不携带图片引用，也不还原工具输出 blob。查询接口不触发旧历史迁移；迁移仍由会话存储初始化统一完成。
- 展开具体工具后，工具详情接口才返回该工具的图片引用。正文与首屏缩略图（含浏览器解码）就绪前，在原工具行下显示局部加载状态；就绪后一起展示，横向不可见图片继续按可见区域加载。加载失败的图片不阻塞正文，关闭或切换工具时迟到结果不恢复已关闭内容。已有实时正文在后台详情刷新期间保留，避免旧响应或刷新造成内容消失。
- 过程栏外的汇总缩略栏仍独立消费过程摘要的图片引用；它与工具详情共享原有有界缓存及 URL，不依赖过程列表加载。

- 原始 ACP 日志保留审计帧；新写入 Timeline 的图片 Base64 统一进入既有内容哈希 `acp.file-blobs`，Timeline 引用 blob。过程摘要/实时消息只提供原事件 ID、内容项位置、哈希和声明 MIME，不传 Base64；索引 v11 投影图片引用，历史工具详情分页不能导致早期图片丢失。索引版本变化复用既有派生索引重建机制，不改写原始日志。
- `get_acp_image` 接收完整 attempt/branch locator 与图片引用，在后台通过原事件索引验证引用及版本，只读取该图片 blob；检查路径归属、Base64、真实图片格式及尺寸。格式以实际字节为准，允许修正声明 PNG、实际 JPEG 的展示 MIME。错误使用 `acp.image-*` 结构化码。
- 工具详情先提取图片引用，再移除两个已知位置的图片正文后 hydrate 文本 blob；即使 Agent 同时返回标准与扩展图片，也不能把未选用图片的 Base64 带到前端。

## 资源预算

- 每个工具/过程段最多投影前 256 张图片引用；单图最多 24 MiB Base64、16 MiB 原始字节、16 Mi 像素、单边 16384 像素。缩略图最长边 192px；客户端与后端各最多同时执行 2 个图片读取/解码。限制集中在图片模块常量中，不散落到工具实现。
- 两处缩略入口共享按完整作用域及图片版本定位的同一请求、Blob 和 Object URL；原图为独立按需变体。共享缓存最多 80 项、48 MiB 编码字节，包含有界待处理请求；只淘汰无消费者的条目并释放 URL，满载时局部失败可重试。离开可见区域释放缩略租约与组件中的重数据，非活动图片 Tab 不挂载大图。
- 性能与过度设计审视：复用工具身份、过程段、Timeline blob/index、图片菜单与看板，不新增 canonical 图片实体或生命周期。图片引用随内容项数量线性投影；正文不进入首屏/列表摘要，不为生成缩略栏加载工具详情；缓存用于两个真实展示入口的资源共享，不用于掩盖全量历史加载。

## 验收

- 固定标准优先、扩展兜底、未知结构不处理、标准坏图不兜底。
- 小图片也存 blob；摘要/实时事件/工具详情不传图片正文；旧引用与跨作用域引用不能读取其他图片。
- 两个入口只发一次缩略请求并共享同一 URL；不可见图片不请求；淘汰释放 URL；右键操作使用原图及实际 MIME。
- 正常宽度、窄窗口、明暗主题下检查过程栏、图片栏、附件、diff、回复的顺序，水平滚动及工作区大图。
- 分层加载回归固定：缺失输出图片 blob 不影响列表及工具引用查询；列表不含 `goldBandImages`；图片读取与浏览器解码期间不展示新工具正文；解码失败显示局部重试并允许阅读正文；关闭后的迟到结果不恢复详情。2026-09-07 已通过后端 2 项及前端 36 项回归，浏览器验证 40 条过程列表零图片请求、18 张图仅预备首屏 9 张及窄窗口布局。新增就绪状态限于当前工具展开生命周期，预备图片引用原缓存资源并在关闭时释放租约，没有新缓存或持久化模型。

2026-09-07 验收：真实会话中的百度截图通过标准化事件、Timeline blob 存储、索引读取及桌面解码回放，实际为 1449x772 JPEG（声明 PNG）。生产构建浏览器验证两处缩略图共享 URL、按可见区域加载、横向滚动、原图 Tab、右键菜单和明暗/窄窗口布局。核心、桌面和前端回归及类型检查通过；没有增加依赖或独立图片生命周期，资源预算与实现一致。EXE 原生窗口不属于本次已执行验证。
