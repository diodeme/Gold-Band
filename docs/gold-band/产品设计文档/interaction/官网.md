# Gold Band 官网

## 产品目标与边界

- 官网为独立 Vite/React 构建，入口在 `marketing/site`；不改变桌面客户端主入口。
- 桌面 `styles.css` 显式声明其源码扫描范围，避免 Tailwind utilities 依赖调用方构建根目录；官网不覆盖桌面组件样式。
- 官网固定深色，中英文通过 `/zh/` 与 `/en/` 切换；Documentation 和 Demo 先提供独立占位页面。
- 首页按会话前、会话中、会话后、个性化四章组织。内容依据推广文章与现有产品能力，不使用未经核实的性能、安装量或兼容性宣传。
- 桌面左侧 sticky 演示，右侧滚动文案。触摸设备及窄屏使用自然纵向滚动，每章严格先演示、后文案，不劫持手机滚动。
- 下载入口指向 GitHub Releases。官网不承诺提供移动客户端。

## 演示素材与交互

- 使用 rrweb 官方录制与 rrweb-player 官方回放；文本、光标、文件预览和 viewport 变化作为 DOM 事件保存。
- 每种语言四个独立深色片段，使用同一示例任务。独立 preview 入口复用真实 App、prompt-kit、文件工作区和响应式布局，示例 API 仅在该入口覆盖。
- 素材是受控示例数据下的真实前端操作录制，不代表真实 Agent 执行、原生窗口或 EXE 录屏。未验证能力不包装为已执行结果。
- 手机保持录制比例，提供播放、暂停、进度、倍速与全屏；不向手机挂载可操作桌面 App。
- 桌面个性化由用户点击进入交互预览，可更改预览主题、字体，并通过 shadcn/ui Resizable 调整 iframe 实际宽度。栏位切换复用客户端布局算法，不复制断点。
- 拖拽容器保留真实页面坐标，仅缩放内部 iframe；不得缩放整个 Resizable Group，避免手柄移动距离与鼠标位移不一致。
- 官网始终深色，个性化预览可以独立切换浅色；录制素材始终深色。

## 数据与生命周期

- 静态内容仅四章双语，属于官网内容领域。示例会话属于 preview 领域，唯一事实为 scenario snapshot，由同一函数派生 run/session/lifecycle 投影。
- 路由表达页面与语言；不新增存储、后端接口或用户账号状态。
- 首屏先显示 PNG 海报；播放器代码异步加载，只有当前可见章请求 JSON。同一时刻最多一个播放器或一个交互 iframe。
- 生成素材时遍历已解析的事件结构，将捕获源站地址迁移为同源相对路径；字体等资源随站点分发，不依赖开发服务器。
- 切章、切语言、离开页面销毁播放器、监听器、RAF，并取消旧请求；页面隐藏时暂停播放。
- 录制最多 60 秒、12 MiB、12,000 events；复用现有有界录制缓冲。四章上限固定，无无界缓存。
- 加载、成功、失败可区分；失败保留海报并支持重试。减少动态效果偏好默认不自动播放。

## 方案评审

- 根因判断：桌面响应式设计已成立，官网需要正确消费实际 viewport 与录制内容，属于新展示载体的实现完善，不是桌面设计缺陷。
- 过度设计：复用现有组件和成熟 rrweb，不添加视频引擎、移动客户端、数据库、状态管理框架或新缓存。
- 性能：主要风险为桌面 App 体积与录制 JSON；App 只在交互入口按需加载，回放不运行 App。滚动使用 IntersectionObserver，尺寸仅通过 RAF 更新 DOM，不在页面根 state 保存连续像素。
- 验收：接口单测、独立类型检查和生产构建；桌面/手机双语、章节切换、回放控制、预览主题字体与收缩恢复、非当前素材不加载、资源销毁与请求失败恢复。

## 开发与构建

- `npm run site:dev`：本地官网。
- `npm run site:record`：在开发服务器下重录双语四章素材。
- `npm run site:build`：独立类型检查与生产构建。
- `npm run site:preview`：预览生产产物。
- `npm run site:test`：官网与录制接口回归测试。
- `npm run site:verify`：使用 agent-browser 验证生产页面，默认地址为 `http://127.0.0.1:1441`。可通过 `SITE_URL` 和 `AGENT_BROWSER_BIN` 指定地址与 CLI 可执行文件。
- 静态部署需将不存在的页面路径回退到 `index.html`，保留真实资源与 `preview.html` 路径。预览页禁止搜索索引。
- 字体与图标沿用仓库已有资源和授权声明；生成 JSON/PNG 为可再生成的官网素材。
