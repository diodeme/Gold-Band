# 内置主题立意与设计理念

面向用户的主题故事文案真源。生成更新日志（`release-notes/<版本>/`）介绍新增主题时，从这里取用「一句话」与「立意」段落；技术参数（token 色值、能力声明、壁纸规格）以 `interaction/app/settings.md` 主题清单为准，两处各司其职，不互相复制。

## 画境 / Vista（`builtin.vista`）

**一句话**

> 画境：白日是摊开的水彩长卷，入夜是黑金雪峰与星空——两景皆入画。配色取自两景（黛青 × 金杏），与 Logo 色系完全解耦。

**立意**

画境把两幅画装进一套主题：白日的水彩长卷——暖纸为底、黛青点染、人物松亭皆是人间烟火；入夜的雪峰星空——近黑画布上金杏色的光。深浅两套方案各取一景，配色与壁纸同源。

**设计理念**

- 深色「雪峰之夜」：近黑画布 `#0f0e10` 配金杏主色 `#E8A54A`——像雪峰在夜色里被最后一缕光镀金；壁纸是黑金雪山与星空。
- 浅色「水彩长卷」：暖纸底 `#faf8f4` 配黛青主色 `#2F6157`（画中青黛颜料）、去饱和砖红 `#B0483F` 留给危险族语义；壁纸是纸墨水彩人物图。
- 配色刻意与 Logo 三色（朱红/藏蓝/杏橙）解耦——那组颜色留给未来可能出现的品牌主题，画境有自己的色彩身份。
- 不想用壁纸？壁纸设置里可以一键禁用主题壁纸；性能优先模式下壁纸自动关闭。

## 春野 / Meadow（`builtin.meadow`）

**一句话**

> 春野：一款真正护眼的春意主题——浅色春芽绿画布比纯白少约 15% 的入眼光量，深色「春夜」以嫩芽绿点亮沉静松林，阅读区护眼、代码区清晰。

**立意**

冬日之后原野上的第一抹新绿。护眼不必将就美感：我们测量了画布亮度与绿色饱和度，让它落在真正减少视觉疲劳的区间——比纯白暗一档、绿意可感知但不铺墨，是「春天的白墙泛出绿意」，不是「整片绿纸」。

**设计理念**

- 浅色「春晓」：春芽绿画布 `#E4EEDF`（相对亮度 0.845，入眼光量比纯白少约 15%，绿意经过校准可感知且不饱和），浮层卡片保持近白——清新层次靠「画布沉、卡片浮」的对比维持。
- 深色「春夜」：低饱和松绿底 `#202624`，嫩芽绿主色 `#7FC494` 点亮，文字用亮白绿而非灰绿——暗而不闷。
- 阅读区护眼、代码区清晰：代码与 Diff 使用更亮的「纸面层」承载语法高亮，长会话舒适、代码仍然锐利。
- 全色板压制蓝光（链接保留唯一的低饱和钢蓝），全部文字对比通过 WCAG AA，护眼不牺牲可读性。

- 每套主题提供「一句话」与「立意」两段：短公告用一句话，版本详情页用一句话 + 立意 + 设计理念节选。
