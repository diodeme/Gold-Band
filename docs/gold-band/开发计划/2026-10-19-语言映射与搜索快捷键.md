# 语言映射与搜索快捷键

## 范围与根因

- 中文 locale 映射在 Rust 与前端均把地区和文字标记放进同一判断，导致 `zh-Hans-HK/TW/MO` 选为繁体。修复现有映射契约：显式 `Hans/Hant` 优先，无文字标记才按地区判断。
- 会话搜索已有独立弹窗、查询状态和侧栏入口，缺少键盘入口。复用现有组件及 `open/onOpenChange`，不另建搜索状态或快捷键框架。
- `desktopLanguage` 仍是语言偏好的事实源，仅缺失时初始化。Windows 系统语言仍走 UI LANGID；本次不自动改写已保存的语言。

## 方案自评审

- 过度设计：复用原有映射函数、Dialog/Input 和开关状态；不增加依赖、持久字段、缓存、队列或第二套搜索接口。
- 性能：locale 只扫描短标签；键盘事件先做固定条件判断；仅搜索动作更新弹窗状态。搜索数据量可随历史增长，但本次不增加历史加载或查询次数，继续使用既有 300ms 防抖与 20 条结果上限，无需新增 benchmark。
- 验收复核：生产改动仅涉及现有语言映射和搜索组件；浮层判断只在匹配快捷键后沿目标祖先查找，没有全 DOM 或历史扫描。未引入额外刷新、持久化或 I/O，无明显新增性能风险。
