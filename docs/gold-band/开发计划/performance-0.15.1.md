## 最终验收

- Release 定位基准：1千 / 1万 / 10万条、16 次读取由 114 / 1,186 / 11,538 ms 降到 20 / 48 / 529 ms；包括首次冷加载，不代表图片解码或页面端到端耗时。
- Timeline 34 项通过，2 项按设计忽略（release benchmark 已单独执行，另一项需要本地历史 fixture）。覆盖一次索引加载、普通追加、压缩 generation 失效、8 线程共享冷加载、工具顺序更新、LRU 数量/字节预算、v10 字节不变与旧图片 32+8 分页。
- 桌面目录 5 项通过，覆盖 worktree Skills、ACP 优先、内容变化事件、落盘失败重试与被同名 ACP 遮住的 Skill 变化。后两项先观察对应失败，再分别修复写入顺序和变更比较来源；核心图片协议另有 2 项通过。连同 Timeline 和前端，本轮相关回归共 54 项通过。
- 前端 6 个测试文件、13 项通过：作用域共享、实际 projectId 事件过滤、20 次事件合并一次后续请求、迟到响应隔离、局部诊断合并、图片可见性/分页暂停恢复/重入/游标异常，以及原图片缓存和工具展示回归。
- `cargo check -p gold-band-desktop` 和 `npm run web:build` 通过。保留既有 dead-code、混合静态/动态导入和大 chunk 警告；无新增依赖。
- 生产构建 Chrome `/chat/agents` 验证环境诊断完成状态及宽/窄窗口。临时图片 fixture 使用实际 React 组件与模拟 API，验证 6 张图片、2 页请求、隐藏重入仍为 2 次、窄窗口无页面横向溢出、图片解码完成、console 无 error。宽窗口截图正常；窄图片视口截图接口超时，以 DOM 尺寸/解码结果作为替代证据。
- 未把浏览器模拟数据验证当作 EXE 原生 IPC 端到端验证；IPC 后端通过编译及领域接口测试覆盖。本次未启动实际 Agent 或 EXE 客户端。
- 过度设计审视：复用既有 locator/generation、文件锁、LRU 容器、Tokio semaphore 与图片控件；只增加有容量上限的派生定位投影和组件内分页进度。目录写入在内容变化时暂存至多 256 项的副本，确保落盘失败可重试；不增加 canonical 图片实体或全历史回填队列。
- 性能边界：索引首次解析仍为 O(N)，LRU 预算是驻留估算而非峰值 RSS；失效恢复沿用既有路径。热单条读取为哈希定位加单记录 I/O；旧图片每页最多 32 个工具，引用最多 256；全局 LRU 锁不覆盖文件 I/O，诊断事件不再触发无关目录请求。
- 临时 HTML/TSX fixture、1427/1428 验证服务和本次 Chrome Tab 已清理。
