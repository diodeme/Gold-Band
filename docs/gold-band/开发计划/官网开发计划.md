# 官网开发计划

## 已确定范围

- [x] 官网独立构建、深色主题、中英文路由与导航。
- [x] 首页四章：会话前、会话中、会话后、个性化。
- [x] 桌面左演示右文案；手机每章上演示下文案。
- [x] Documentation 与 Demo 独立占位。
- [x] 复用真实桌面组件的独立示例 API；官网不修改运行时接口。
- [x] 当前章懒加载回放、资源释放、减少动态偏好与失败重试。
- [x] 桌面按需交互预览：主题、字体与可拖动宽度。
- [x] 生成双语四章深色录制与海报，核对内容与资源。
- [x] 接口单测、类型检查、生产构建。
- [x] 桌面与手机实际浏览器验收，记录结果。

## 实现约束

不新增移动客户端；手机只播放演示。官网固定深色，预览主题独立。成熟实现优先：React、Tailwind、shadcn/ui、prompt-kit、rrweb、react-resizable-panels。当前章节只有一个活动播放器或 iframe，无持久化示例数据与后端依赖。

## 验收评审

性能验收核对首屏请求边界、录制体积、并发播放器数量与隐藏页面暂停；以生产构建验证资源路径。过度设计验收检查新增依赖、状态与接口是否必要。发布与真实 EXE/Agent 执行不属于此次浏览器演示验收。

### 验证发现与修正

- 独立构建暴露 Tailwind 扫描范围隐式依赖构建根目录；显式声明桌面源码范围，恢复实际组件样式。
- 初版会话中录制仅有 metadata/full snapshot/end 三事件。最小素材测试在未修复时失败；检查客户端契约确认预览更新漏传 `taskUuid`，被作用域校验拒绝。补齐 sidebar 与事件身份，不放宽桌面校验；重新录制后使用同一测试验收。
- 交互预览使用页面坐标驱动 Resizable，仅缩放 iframe，避免拖拽坐标与整个 Group 的 transform 混用。浏览器验收断言手柄移动 350px 与指针移动一致，并检查 3/2/1/3 栏位变化。预览加载期间禁用主题、字体切换，避免对尚未就绪的 iframe 调用 API。

## 2026-09-05 验收结果

- `npm run site:test`：9 项测试通过，覆盖路由、双语章节、生命周期投影、素材变化与容量、录制缓冲以及资源地址迁移；会话中静止录制的原失败测试已转绿。
- `npx tsc -p marketing/site/tsconfig.json` 与独立 Vite 生产构建通过。
- `npm run site:verify`：中英文分别验证 1600×1000、768×1024、390×844、320×740。四章切换、手机媒体先于文案、无横向溢出、单个活动回放全部通过。
- 桌面按需预览验证深浅色、等宽字体、拖拽位移与 3/2/1/3 栏位；退出该章后 iframe 销毁。
- 实测栏宽：`256/701/440 → 0/414/440 → 0/547/0 → 256/701/440`。
- 手机尺寸下验证暂停、2×、进度跳转与原生全屏缩放；注入 HTTP 503 后局部错误出现，重试恢复。
- Documentation/Demo 双语占位路由、页面语言、语言切换目标与无 iframe 请求通过。
- 结构化浏览器报告与截图路径保留于 `.codex-temp/site-verification/report.json`；录制脚本与验收脚本可重跑。

### 最终自评审

- 过度设计：没有新增数据库、移动产品 UI、应用状态管理或依赖；继续复用已有 rrweb、shadcn/ui 与客户端组件。
- 性能：首屏没有请求 preview、webview-bootstrap、Mermaid 等桌面重模块；最多一个活动回放或预览。八段 JSON 约 0.57–1.12 MB，构建报告 gzip 约 112–180 KB/段，海报约 62–117 KB。站点部署应启用静态压缩与缓存。
- 构建仍报告桌面复用模块的大 chunk 和已有 plugin-opener 混合导入警告；这些模块没有进入官网初始加载路径，不为此次展示新增分包框架。
- 边界：验证使用 Chromium 的桌面与移动视口，不等同于 iOS/Android 真机验收；原生全屏依赖浏览器能力。演示是真实前端在独立示例数据上的回放，没有启动真实 Agent、原生对话框或 EXE。
