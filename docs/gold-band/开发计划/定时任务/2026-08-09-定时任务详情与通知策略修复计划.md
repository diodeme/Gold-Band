# 定时任务详情与通知策略修复实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复定时任务详情页初始化白屏，并确保定时任务完成通知开关能够唯一控制成功完成通知。

**Architecture:** 会话导航函数必须在任何页面内容求值前完成初始化，避免详情分支读取暂时性死区变量。带 `scheduled_occurrence_id` 的 lifecycle 事件由定时任务运行时转换为专用通知，通用会话通知订阅器不再重复消费，普通会话通知保持原行为。

**Tech Stack:** React 19、TypeScript、Vitest、Rust、Tauri、Cargo test。
