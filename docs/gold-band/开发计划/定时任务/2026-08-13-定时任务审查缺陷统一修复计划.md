# 定时任务审查缺陷统一修复实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:test-driven-development task-by-task. Each production behavior must be preceded by a failing regression test.

**Goal:** 修复定时任务精确对账、终态副作用、deadline 事件、设置并发和管理错误闭环，并将 occurrence 历史改为每页 20 条的稳定游标分页。

**Architecture:** occurrence 使用完整 Task/Run locator 对账，lifecycle 与恢复共用终态收敛管道；SQLite 以三字段 keyset cursor 提供有界历史页。前端以目标实体级请求状态和 mutation generation 管理异步结果，错误保留当前 canonical 数据。

**Tech Stack:** Rust 2024、rusqlite、Tauri 2、React 19、TypeScript、Vitest、shadcn/ui、Tailwind CSS。

### 验收结论

- 正确性：精确 Run 对账、统一终态副作用、持久化 deadline 事件、设置并发、管理错误闭环和历史游标分页均有接口级回归。
- 性能：历史分页固定最多读取 21 行，状态筛选命中专用复合索引；诊断计数使用 SQL 聚合且只加载最新 20 条明细。未引入全历史加载、轮询、N+1、无界缓存、扩大的锁范围或渲染范围。
- 兼容性：既有 scheduler、desktop runtime/service、commands 和 1089 项前端测试全部通过；生产构建、Rust check、格式与 diff 检查通过。
