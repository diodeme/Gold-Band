# Gold Band 定时任务开发计划

## 目标

为 Direct、Workflow、AUTO 增加统一的定时触发能力，复用现有 Task/Run/ACP 生命周期，并提供 composer 创建入口和左侧定时任务管理页。

## 已确认范围

- 定时任务是触发层，不是第四种运行模式。
- 支持 `At`、重复预设、固定间隔 `Every`、自定义 Cron。
- `Every` 只支持分钟和小时；首次启用记录 `anchorAt`，暂停不补跑，重新启用或修改间隔时重新起算。
- Workflow/AUTO 只能新会话；Direct 支持新会话和持续会话。
- 默认启用队列保护；关闭后按 30 秒间隔最多重试 3 次。
- 错过执行不补跑。
- 会话使用 AlarmClock 图标标注，不增加任务名称字段。

## 实施任务

### 1. 领域模型与持久化

- [x] 在 Rust runtime 增加 `ScheduledTaskDefinition`、`ScheduleSpec`、`EverySpec`、`OverlapPolicy`、`ScheduledTrigger` 等类型。
- [x] 在 scheduler store 增加 per-project `scheduled-tasks/` 路径、原子写入、触发记录和输入附件复制。
- [x] 实现 `scheduled-task.json` 校验：模式与 session policy 约束、IANA 时区、Every 正整数和分钟/小时枚举。
- [x] 为 task content 建立稳定指纹；Workflow/AUTO 的 Agent 身份、Agent 策略和可用 Agent 集合属于 authoring 并参与指纹，只有 model、thought level、permission 和 Direct session policy 不参与指纹。
- [x] 为 schema 添加 Rust 接口层单元测试，覆盖非法单位、非法模式、空指纹和重复启用。

### 2. 调度计算器

- [x] 使用成熟 Cron 解析/计算库实现 `At`、每小时、每天、工作日、每周多选和自定义 Cron。
- [x] 实现 `Every` 的 anchor 计算、暂停/重新启用重置和间隔编辑重置。
- [x] 明确 timezone 的 wall-clock 计算；`Every` 使用绝对时间间隔。
- [ ] 实现 missed 记录和下一个未来时间点计算，不生成补跑 run。
- [ ] 为边界时间、周日跨周、多选星期、DST 和 Every 重置行为添加接口测试。

### 3. Scheduler 与队列保护

- [x] 新增后台 scheduler service，启动时加载 enabled 定义并恢复 next occurrence。
- [x] 对 running、permission waiting、AskUserQuestion、waiting-for-user 和 resumable paused 统一识别 active。
- [x] `skip_when_running` 直接写入 skipped trigger；`retry_when_busy` 使用 30 秒间隔和最多 3 次尝试。
- [x] 调度器只创建 trigger 并调用 App 既有 task/run API，不直接修改 run canonical state。
- [x] 覆盖重启恢复、并发触发、重复 retry、禁用/启用和进程关闭测试。

### 4. Task/Run/ACP 集成

- [x] 增加创建、更新、启用、暂停、删除和查询 scheduled task 的命令接口。
- [x] Workflow/AUTO 根据 content fingerprint 复用 task 或在下一触发物化新 task；每次内容不变的触发创建新 run。
- [x] Direct new 每次创建 task/run/session；Direct continuous 复用 session 并发送新 prompt。
- [x] 运行时冻结 Workflow/AUTO 的 authoring 快照，并将执行配置写入 run/session metadata。
- [x] 为 Direct Agent 不可修改、Direct workspace/content 变化、Workflow/AUTO Agent/authoring 变化和 model/thought level/permission 变化分别增加回归测试；验证 Workflow/AUTO Agent/authoring 变化后下一次触发创建新 Task，仅执行配置变化时复用 Task 并创建新 Run。

- [x] 增加 `web/src/routes.ts` 和 `web/src/App.tsx` 的定时任务管理路由。
