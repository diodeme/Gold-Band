# 定时任务运行时实现补充

## 已完成

- [x] 管理页使用任务内容摘要，不展示 `scheduled-UUID`。
- [x] 管理页显示中文调度摘要、中文时区、下次执行时间和状态。
- [x] Tauri 启动后台 scheduler loop，扫描当前及已配置工作区。
- [x] 创建定时任务时只保存定义；到点执行时才物化 Task 并写回 `taskId`。
- [x] 使用 `lastTriggerAt`、`lastTriggerStatus` 和重试字段实现轮询幂等与队列保护。
- [x] Direct、Workflow、AUTO 均接入现有 Task/Run/ACP 创建链路。
- [x] 单次任务完成后自动停用。
- [x] 浏览器预览与桌面端均保留多个定时任务定义，连续创建不会覆盖已有任务。
