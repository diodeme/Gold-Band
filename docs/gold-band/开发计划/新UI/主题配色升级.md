# Gold Band 主题配色升级计划

## 1. 问题与目标

旧主题的主要问题不是单个色值不好看，而是背景、内容面、侧栏、边框和交互强调之间缺少稳定的语义层级：默认浅色被冷蓝大面积染色，旧深色则由香槟金同时承担品牌、操作、选中和焦点语义。

本轮目标：

- 四套主题继续共享 Tailwind CSS + shadcn/ui semantic token 接口，禁止页面级配色分支和硬编码。
- 浅色以中性 surface 为主体；品牌色只用于操作、焦点、选中和状态。
- 深色参考成熟桌面 AI 工具的中性灰阶最佳实践，保证背景、内容面、浮层和边界清楚可辨。
- 设置页主题预览与 CSS runtime 色板保持一致，主要文字和状态色满足 WCAG AA。

## 2. 色板方向

### 2.1 默认浅色

- 瓷白主面、雾灰工作区、石墨文字与低饱和矿物靛蓝强调。
- 蓝色不得大面积铺入页面底、侧栏和边框。

### 2.2 暖色浅色

- 暖瓷白、燕麦灰、深咖文字与古铜金强调。
- 减少黄色铺底，避免陈旧和泛黄感。

### 2.3 石墨深色

- 按 Codex 桌面端截图取样，以 `#181818` 主内容、`#202020` 侧栏/标题栏、`#242424` 内容面、`#2d2d2d` composer/高层 surface、`#313131` 选中面建立无彩炭灰层级。
- 选中、按钮和焦点不再使用品牌蓝；冷蓝只承载运行状态，暖橙只承载权限/警告。

### 2.4 终端黑

- 与石墨深色共享无彩层级逻辑，但整体压暗为 `#111111 / #191919 / #1b1b1b / #252525 / #2d2d2d`。
- 作为比石墨深色更安静的沉浸选项，不使用蓝色或灰紫铺满背景与选中态。

## 3. 实现范围

- 更新 `web/src/styles.css` 中四套主题的 semantic CSS variables。
- 更新 `web/src/theme.ts` 中设置页主题预览色板。
- 同步中英文主题名称和说明。
- 侧栏所有选中态必须使用 `sidebar-accent` / `sidebar-accent-foreground` 成对语义 token，覆盖主导航、运行项和会话切换器。
- 共享 shadcn `TabsList` 默认 track 使用 `secondary` surface + `border` 内描边，避免默认浅色的 `muted` 与 workspace 同色；`line`、Agent 图标和自带边界的透明变体不改。
- 不修改页面布局，不新增组件，不改变主题持久化数据结构。

## 4. 验收

- Vitest 固化 CSS runtime 色板、设置页预览色板和主要前景色 WCAG AA 对比度。
- 源码契约测试固化侧栏选中背景与前景的语义配对，禁止回退为 `text-sidebar-primary`。
- 源码契约测试固化默认 Tabs track 的 `secondary` / `border` 语义，覆盖所有复用默认变体的页面。
- Web 生产构建通过。
- 实际启动前端验证设置页、会话首页、侧栏、标题栏、composer 和配置区域。
- 默认浅色、暖色浅色、石墨深色和终端黑具有可辨识的独立气质，同时保持统一的信息层级。
