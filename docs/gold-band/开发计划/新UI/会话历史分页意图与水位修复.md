## 修复契约

1. 普通 scroll 的顶部阈值只消费已经成立的历史意图，布局和程序性位移不自行进入历史分页。
2. 顶部有历史的短窗口也允许真实上翻。输入归属继续由共享 ChatContainer 过滤；有效请求进入既有 `user-wheel/key-up` 生命周期，ACP 通过 follow cause 投影 manual 意图，不另写一份意图来源。加载后仍不足一屏或仍在底部容差内时，卸载重进也不得恢复自动跟随。无 overflow 的明确向下输入直接完成既有 resume，因为此时不会产生原生 scrollend；有 overflow 仍等待稳定 scrollend，程序位移和布局钳制不授予资格。
3. older 合并保留当前窗口的 newer gap，并计入尾部裁剪和 replay 缺口；不直接使用返回旧页的 `hasNewer`。
4. 同 generation 的旧页暴露更高 canonical 水位时，按提交时当前窗口的已覆盖水位判断是否需要校准，复用 recovery 协调器。旧页不推进正文窗口 coverage，不抢占历史；用户回到最新必须确认该水位，而非仅滚动到陈旧 DOM 底部。历史窗口接近底部时的 newer 分页只消费共享组件已有的明确向下输入资格，布局或程序性 scroll/scrollend 不能借真实缺口抢回 head；只开放既有资格的只读查询，不另存方向状态。
5. 用户恢复最新时若 older 尚未返回，复用现有 single-flight/trailing handoff，等分页释放后再查询 head，不能让旧响应再次永久关闭跟随；自然向下、显式回到最新及发送复用入口遵守同一交接。期间再次上翻则继续保护历史，不自动发 head，并结束此次恢复命令的展示 pending，让按钮可以重新操作；canonical 缺口和 loss gate 不因此清除。
6. 无历史的短窗口、内部工具滚动、编辑控件、缩放手势和单纯滚动条按下不因新增入口退出跟随。保留单请求、owner/generation 校验、稳定消息 identity 与默认 96 项/页、288 项窗口。

## 修复前证据

- 布局滚动复现：处于 live head、有 older、底部仍落在顶部阈值内，无用户输入时产生一个意外 older 请求；新正文缺失、“回到最新”出现且 follow=false。最终测试夹具在完整撤回本次实现增量后再次确认四项直接失败。
- 旧页标记复现：短窗口 wheel/key 上翻，older 响应 `hasNewer=true` 时发生 `head → older → newer → head`，请求由 2 次变 4 次且刚加载的历史消失。修复后同一用例仅 `head + older`，保留历史 DOM。
- 设计复核发现的短窗口重入遗漏：前一版只写 ACP manual 标记；600/600/top0 的 wheel/key 用例在上翻、卸载重进后仍 report atBottom=true，live 正文进入历史窗口且按钮缺失。真实生产 Chrome 的 534/534/top0 也出现相同转换，诊断只有 external-stop-scroll，重进后出现 external-scroll-to-bottom。
- 新水位复现：窗口 coverage=10，older 只返回 item1 但 canonical coverage=11，延迟 live11；点击回到最新只发生本地滚动，总请求仍为 2（预期 3），canonical11 不可见。生产浏览器另以 live 更新到11、后端持久化12但不发布 live12 复现：older 暴露 coverage12，点击后仍只有初始 head 和 older 两次请求，正文缺少12。

- 联动复现：新水位被识别后，短窗口仅派发普通 scroll/scrollend 就产生 4 次请求而非 2 次，历史被自动 newer/head 追平。新增门禁使用共享组件既有向下资格，不让几何位置制造恢复意图。
- 无 overflow 恢复复现：短窗口上翻后真实 wheel-down/PageDown 不产生 scrollend，旧实现不恢复，后续 live 正文仍被挡住；改为仅在无 overflow 的明确向下输入链完成既有 resume。
- 在途顺序复现：短窗口 up 发起未决 older 后 down 已恢复，但 older 晚返回再次执行 external-stop-scroll；后续正文虽进入 DOM，增长后的 scrollTop 仍为 0，未达到预期底部。恢复命令与在途分页必须沿现有 single-flight/trailing handoff 协调，不能由晚返回响应覆盖更新的用户意图。

- 取消待恢复命令的中间态复现：older 未决时点击回到最新，再次上翻后释放 older，未发多余 head、历史保留，但按钮一直 disabled；生产 Chrome 确认没有组件异常且请求仅2次。取消用户恢复命令必须同时结束展示 pending，仍保留真实 canonical 缺口，以便再次点击可以重新追平。
