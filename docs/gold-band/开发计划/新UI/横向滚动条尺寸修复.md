# 横向滚动条尺寸修复

- 根因：主题接入在共享 ScrollBar 的两个方向均设置最小高度，导致横向滑块越出细轨道。属于正确设计下的实现错误。
- 方案：保留 shadcn/Radix 组件及主题 token，按 orientation 将最小长度映射到宽度或高度。
- 失败证据：`scrollbar-orientation.test.tsx` 修复前横向用例失败（期望 min-w，实际 min-h），竖向用例通过。
- 回归：同一组件接口测试覆盖两个方向；主题滚动条既有测试、类型检查、生产构建与浏览器几何/视觉验收。
- 性能与过度设计评审：仅修正 CSS 轴向约束，无新依赖、状态、请求、扫描、缓存或渲染订阅；图片资源预算不变，不需 benchmark。
- 验收完成：方向回归与既有主题测试共 10 项通过，`npm run web:build`（含 TypeScript）通过，保留既有混合导入和大 chunk 告警。内置 iab 不可用后使用已连接 Chrome，在真实共享组件隔离页验证浅色/深色、280px/560px 容器及拖动；轨道约 10px、可见滑块约 3px，滑块未越出轨道。未执行真实会话或 EXE 验证；临时页面和测试服务已清理。
