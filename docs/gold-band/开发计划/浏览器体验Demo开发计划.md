# 浏览器体验 Demo 开发计划

## 边界

独立浏览器产品体验，不实现官网，不改变桌面 API 契约与后端。仅开放预设内容浏览、临时配置和外观设置；Git 页面仅展示假数据，不执行 Git 或业务写入。

## 管理与工作区演示补全（2026-09-09）

- 复用客户端“更多”导航及需求看板、定时任务列表/详情，增加对应 hash 深链接。
- 固定四条需求、两条定时任务，每条两次执行记录；业务列表返回摘要，正文按需读取，未知 ID 拒绝访问。
- 快速对话保留定时模式切换与本地配置，实际发送、创建任务禁用；现有任务可查看编辑表单，保存禁用。
- 源码管理复用原假数据与只读 Diff/历史，Git 写操作禁用；运行目录按 locator 展开并读取固定 Markdown 文件。
- 桌面端 API 与后端不改动；共享组件的只读上下文默认 false，原桌面交互保留。
- 过度设计与性能评审：无新依赖、后台服务、业务持久化或缓存；小规模固定样例、页面懒加载，沿用现有组件与数据仓库生命周期。
- 验收：13 个测试文件、78 项测试通过，覆盖 Demo API/路由/只读导航、定时配置本地完成与业务保存隔离、原定时任务 API 与源码仓库组件/数据仓库回归。Demo 和桌面 web 类型检查、生产构建通过；未运行 EXE。
- Chrome 生产版验证需求四列、准备需求后只读输入预填、发送模式切换、配置本地完成、定时详情及禁用保存、运行目录 reports/review.md 正文、Git Diff 和提交历史。390px 下源码管理沿用 Sheet，定时列表 scrollWidth=390；语言切换同步更新样例标题，重新拉宽恢复桌面布局。
- 最终加载验证未见应用控制台错误。中途重建产物后旧页面的懒加载未完成，重新加载最终构建后目录、Diff、历史均正常；部署更新需刷新旧页面。
- 源码历史复用现有 303 条固定预览记录及分页，不增加全量历史首屏读取。Demo 主包 gzip 约 1039 kB，沿用既有大包及静态/动态导入警告，未引入新性能机制。

## 运行与部署

- `npm run demo:dev`：本地开发，默认 1450 端口。
- `npm run demo:build`：类型检查并输出 `.codex-temp/demo-dist`。
- `npm run demo:preview`：本地预览生产构建，默认 1451 端口。
- 将产物部署到独立静态站点根路径；使用 hash 导航，静态服务器无需业务路由重写。
- 后续客户端共享组件改动后重新构建 Demo；新增业务 API 默认关闭，需显式评估是否开放。

## 自评

不新增依赖，不做完整 mock 系统；两条会话、一个 Skill 和固定工作流形成有界数据规模。复用已有文件读取、只读编辑器、主题与布局机制。桌面 API、后端不变；共享 UI 的默认分支需要回归验证。
