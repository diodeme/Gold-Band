## 功能新增/调整

### 1.新增个人数据分析

现在可以在「帮助 → 个人数据分析」中查看自己的使用情况了。

支持查看任务完成情况、累计执行耗时、Token 消耗、Agent 和 Skill 使用情况，并查看耗时、Token 消耗 TOP10，点击任务可跳转到对应会话。

支持按全部、今天、近 7 天、近 30 天或自定义日期筛选。还可以选择 Agent、模型和思考强度，生成针对当前数据的分析建议。

![image.png](https://static.dion.blue/2026/09/20260907160110199.png)



### 2.支持接入 Multica，在客户端执行远程需求

新增「需求管理」页面，连接 Multica 后，可以查看远程工作空间中的任务，并在本地执行。

使用流程如下：

1.连接 Multica，添加远程工作空间。
2.选择需求，点击「执行」，需求正文会带入会话输入框。
3.选择本地工作目录、运行模式等配置，点击「发送」后正式领取并启动任务。
4.执行结束后，将完成或失败结果回传到 Multica。

输入框中会显示绑定的 Multica 需求，发送前可以解除绑定；仅打开需求、还没发送时，不会占用远程任务。




### 3.会话中直接展示本轮生成的附件

Agent 本轮生成的附件，现在会和文件变更一起展示在会话中，点击即可在右侧工作区打开，不需要再去目录里逐个查找。


![image.png|500](https://static.dion.blue/2026/09/20260907160338353.png)


### 4.完善 AUTO 模式的任务协作和结果交接

本次继续==完善多节点并行执行==：

1.节点可以在关键决策前了解其他任务分支的目标和进度，减少重复分工和相互冲突。
2.完善前后节点之间的附件传递，后续节点可以获取当前任务链路需要的材料。
3.AUTO 节点完成后，会生成结果摘要和完整报告清单，供后续工作流节点继续处理，减少交接时遗漏信息。
4.优化新一轮反馈和节点交接的提示词，减少继续执行时偏离当前任务范围的问题。

### 5.调整侧栏入口

将 Agent、上下文、运行模式、需求管理等入口收纳到「更多」菜单，会话侧栏更简洁。

![image.png|216](https://static.dion.blue/2026/09/20260907160457452.png)


## 体验优化

### 1.更流畅的长会话体验

优化长会话的消息渲染、流式工具更新和历史加载，减少持续输出时的卡顿及内存占用。侧栏优先加载首批可见数据，减少历史会话较多时的等待。

修复向上翻阅时被自动拉回底部、返回最新消息按钮状态不稳定，以及加载更早历史时部分内容丢失的问题。

### 2.更稳定的会话执行与恢复

修复切换或重新进入会话后，消息、运行状态和待处理交互不同步的问题；修复删除后新建会话可能混入旧内容、会话结束后侧栏仍显示运行中等问题。

优化异常后的输入框恢复和会话重连，修复 Claude 部分后台执行导致任务提前结束的问题，以及运行中的连接被误回收的问题。

> [!attention] 关于claude节点的特殊处理
> 由于claude code sdk和claude agent acp的局限性，目前claude发起后台任务或者monitor时，前台任务会直接停止，且现在没有合理的手段判断后台任务是否完成且唤醒前台任务继续。故本次临时==将claude节点的后台任务和monitor禁用==了，对于无人值守的长程任务来说，影响很小，后续等待相关组件的进一步优化。
> 
> 详细见issue：https://github.com/diodeme/Gold-Band/issues/114

### 3.其他体验优化

1.改善较旧 WebView 环境中的页面显示、状态颜色和布局兼容性。
2.修复部分会话恢复后模型列表不正确的问题，更新内置 Agent 目录。
3.修复置顶会话和通知跳转定位问题。
4.修复工作流 JSON 编辑时执行槽位配置丢失的问题。
5.其他 UI 样式和已知问题修复若干。

## 0.15.1 补充更新（2026-09-09）

### 功能新增/调整

#### 1.支持查看工具返回的图片

Agent 调用工具返回的图片，现在可以在工具详情中查看。图片在展开详情后才加载，减少长会话中不必要的加载和内存占用。

![image.png](https://static.dion.blue/2026/09/20260909152010624.png)


#### 2.内置 Agent 启动配置随客户端统一更新

内置 Agent 的启动命令和参数改由客户端统一维护，已有 Agent 也会随客户端升级使用新的配置，避免仍使用旧启动参数或旧版本。本次将内置 Claude ACP 适配器版本固定为 `0.72.0`。

> [!attention] 内置 Agent 配置调整
> 如果以前修改过内置 Agent 的启动命令或参数，升级后会使用客户端内置配置，这两个字段也改为只读。名称、图标、环境变量、目录等其他配置保留；需要自行维护启动命令时，可以使用自定义 Agent。

#### 3.Multica 支持修改连接地址和取消连接

连接前可以确认、修改服务器地址，也可以通过「连接地址设置」调整地址或恢复默认值。连接过程中支持取消操作。

### 体验优化

#### 1.进一步优化会话滚动和历史阅读

修复展开、收起工具或思考详情时阅读位置跳动的问题，减少流式输出对正在阅读内容的干扰。

向上查看历史时，不会因详情更新被意外拉回底部；发送新消息后，会恢复最新内容并继续跟随输出。同时修复底部区域边界和滚动条长度异常的问题。

#### 2.完善 AUTO 分支交接和流程图

修复并行分支合并、验收后，后续任务未正确回到上层任务范围继续执行的问题。

分发前发现工作区有未提交内容时，改为一次性提醒 Agent 检查并提交后续分支需要的本次任务改动，不再强制清理整个工作区，减少对无关文件的干扰。新工作树仍从 Git 已提交的 HEAD 创建，未提交内容不会自动带入。

#### 3.其他稳定性优化

1.后台提示请求失败时，在会话中显示错误，方便发现执行中断的原因。
2.修复持续输出期间工具详情加载结果被丢弃、详情难以正常展开的问题。
3.减少计时更新引发的不必要历史恢复和重复处理。
