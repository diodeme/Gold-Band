## 功能新增/调整

### 1.右侧工作区支持内置浏览器

会话、文档里的网页链接，现在默认在右侧工作区的内置浏览器打开，不用切到系统浏览器。
![image.png](https://static.dion.blue/2026/09/20260920132009759.png)

内置浏览器支持：

1.多页签浏览，前进、后退、刷新、地址栏。
2.地址栏可以直接输入网址；不是网址时，用当前搜索引擎搜索。搜索引擎可在「设置 → 通用 → 浏览器」中选择百度、Google 或 Bing。
3.当前页可以在电脑版和移动版之间切换。
4.会话和文档里的本地 HTML，也可以在内置浏览器打开。工作目录里的 HTML 文件默认仍打开源码，需要预览时再点浮层按钮。

「设置 → 通用 → 浏览器」里可以分别选择：对话和文档里的 localhost、普通网站，是用内置浏览器还是系统浏览器。进入内置浏览器后，地址栏输入的内容始终在当前页打开。

行内版本已内置常见开发网站
![image.png](https://static.dion.blue/2026/09/20260920132122154.png)




### 2.支持企业微信远程干预

离开电脑时，也可以在企业微信里处理任务卡住的权限、追问和人工检查。

![image.png](https://static.dion.blue/2026/09/20260920132158466.png)


使用流程如下：

1.打开「设置 → 通用 → IM 远程干预与通知」，扫码接入企业微信。
2.用企业微信给机器人发一条私聊消息，完成一对一绑定。
3.任务需要你处理时，会先发一条详情，再发一张可操作卡片。
4.在卡片上同意或拒绝权限、回答追问、判定人工检查成功或失败。桌面端已经处理过的请求，卡片会显示已处理。

也可以按类型开关通知：权限请求、追问、人工检查，以及 Run 成功 / 失败、回合结束。当前只支持企业微信一对一私聊，不支持群聊和自然语言指令。客户端离线、电脑休眠或断网时，不能保证实时收发。


### 3.新增项目记忆

工作空间可以保存一组跨任务复用的参数，Agent 在执行时按需读取，不必每轮把固定参数再说一遍。

![image.png](https://static.dion.blue/2026/09/20260920132228350.png)


在工作空间列表里点击书本图标，打开「项目记忆设置」。每条记忆包含参数名、参数值和用途描述，支持新增、修改和删除。

当前任务用到的参数会单独记在任务记忆里：任务里有同名参数时优先用任务值；任务里把值清空后，不会自动退回项目默认值。项目记忆适合长期复用的默认值，任务记忆由执行过程维护，目前不单独提供任务记忆管理页。


### 4.权限支持自动批准

权限模式下拉底部新增「自动批准」，默认关闭，可以和原来的权限模式同时使用。

![image.png](https://static.dion.blue/2026/09/20260920132257306.png)


勾选后，后续带允许选项的工具权限会自动选择第一个允许项继续执行，不再弹出权限卡片，也不再发系统通知。已经弹出的权限卡仍需要手动处理；向你提问的卡片不会自动跳过。

触发器会显示「当前权限模式 · 自动批准」。工作流节点、AUTO 和定时任务也会沿用创建时保存的自动批准设置。


### 5.输入框支持选择角色，并用方向键翻阅历史

在输入框输入 `@`，可以选择 Gold Band 角色；输入 `/` 仍然是当前 Agent 的命令和 Skill。选中角色后，输入框和已发送消息上会显示角色标签，悬停可以查看完整角色内容。

![image.png](https://static.dion.blue/2026/09/20260920132317039.png)


已经开始的会话里，光标在输入框第一行时按 `↑`，可以翻阅本会话发过的原文；按 `↓` 翻到较新一条，越过最新一条或按 `Esc` 会回到翻阅前的完整草稿。多行输入时，只有光标在首行或末行才会进入翻阅。


### 6.完善定时任务的触发标识和执行历史

持续会话被定时触发时，消息流里会插入一条轻量分隔线，区分自动触发和手动立即执行，不再混成普通即时发送。

![image.png](https://static.dion.blue/2026/09/20260920132357956.png)


定时任务详情改为按每次真正执行分组查看历史。可以移除已完成的执行历史，对应会话仍保留在会话列表里，之后还能打开继续看。运行中、暂停中或等待你处理的记录不能移除。


## 体验优化

### 1.更稳定的长会话阅读和跟随

向上查看历史时，不会因为自动回到最新、或工具/思考详情展开而把阅读位置带走。发送新消息后，会回到最新内容并继续跟随输出。修复滚动尚未结束时跟随中断、以及自动补齐最新内容时跟丢的问题。

### 2.模型和思考强度按当前模型记忆

现在切换模型会带回模型专属的配置，比如上下文配置，fast模式开关等。

![image.png](https://static.dion.blue/2026/09/20260920134850819.png)


切换模型后，思考强度会尽量带到新模型仍支持的同一档；Fast、上下文等只属于当前模型的选项，不会串到另一个模型上。新模型不支持的项会回退为「不指定」，并在会话里说明，不会因此打断发送。

Agent 选择器和会话列表会显示对应图标。会话里改模型、权限或自动批准，会保留在当前会话，不会把首页的默认配置改掉。



### 3.更稳妥的发送失败恢复

消息还没被 Agent 真正接收时，取消或失败会把完整草稿（含附件、引用）放回输入框，避免内容丢失。已经发出去的消息停止生成后，不会再回填。

修复人工检查后跳错后续节点、侧栏运行状态被冲掉，以及失败原因在重新打开会话后看不到的问题。嵌套 Agent 改动的文件，不再出现在主会话的文件变更里。

### 4.其他体验优化

1.修复 Windows 上偶发卡死无响应的问题。
2.改善 Git 版本识别；源码管理里的 PR 概览信息更完整。
3.Agent 诊断失败时给出更明确的本地化原因，并保留有限的原始输出方便排查。
4.截断文字的提示不再挡住点击；无边框窗口缩放条在打开内置浏览器后仍可拖拽。
5.其他 UI 样式和已知问题修复若干。

> [!attention] 关于 Cursor 节点停止后的上下文
> 由于 Cursor ACP 的限制，当前轮已经开始思考或调用工具后如果点停止，Cursor 可能把这一轮用户消息从后续模型上下文里撤掉。Gold Band 会话里仍会保留这条消息，但接下来直接追问时，模型可能看不到刚被停止的那一轮内容。
>
> 工作流里点「继续」仍会重新带上当前任务上下文。该问题来自 Cursor 适配器，后续等待上游修复。
>
> 详细见 issue：https://github.com/diodeme/Gold-Band/issues/130
