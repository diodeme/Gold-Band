## 功能新增/调整

### 1.工作空间文件可以直接引用到对话

现在可以在右侧工作区的文件树或搜索结果中右键文件，选择「引用到对话」，把工作空间里的文件作为上下文交给 Agent。

![image.png](https://static.dion.blue/2026/09/20260924161115127.png)


### 2.运行中的工作流和 AUTO 支持调整执行计划

工作流和Auto的 Run 里的「编辑工作流/AUTO配置」现在可以分别修改**当前 Run** 和**下一次 Run**。

![image.png](https://static.dion.blue/2026/09/20260924161207707.png)
![image.png](https://static.dion.blue/2026/09/20260924161219080.png)


保存时可以选择：

1.仅当前 Run：后续尚未分发的节点使用新配置。
2.仅下一次 Run：本次执行保持不变，下次重跑或新建 Run 时生效。
3.当前 Run 和下一次 Run：同时更新两边。

已经开始执行的当前节点不会中途切换 Agent、模型或配置，已完成的历史也不会被改写。

会话里的修改只属于当前任务：下一次 Run 的设置不会反向修改项目默认运行模式或模板库。


### 3.桌面端支持七种界面语言

Gold Band 现在支持中文、繁體中文、English、日本語、한국어、Português (Brasil) 和 Español。

可以在「设置 → 通用 → 语言」中切换，选择后立即生效。首次启动且尚未保存语言设置时，会按系统界面语言自动选择一次；无法匹配时使用 English。之后以手动设置为准，系统语言变化不会覆盖已有选择。

Windows 安装程序也会按系统语言显示，无法匹配时使用 English。


## 体验优化

### 1.更稳定的文件工作区和附件预览

发送前已经在右侧工作区打开的附件，发送成功后会继续显示，并自动关联到会话中保存的附件。切换页面或重新进入会话后，不再因为临时预览地址失效而出现图片空白。

文件树刷新时会保留已经展开的目录；离开会话再返回时，会恢复文件的阅读和编辑位置。工作空间里的文件发生变化后，文件正文、文件名搜索、变更 Diff 和源码管理会及时刷新，减少继续显示旧内容的情况。

Markdown 文件恢复为默认实时预览，同时保留源码查看和编辑。未修改的文件刷新时会尽量停留在原编辑器和原位置，减少重复加载与跳动。


### 2.更可靠的内置浏览器

完善单页应用和页内跳转后的地址同步，网站通过 `pushState`、锚点或同页导航修改地址时，地址栏会跟随实际页面更新，同时不会覆盖尚未提交的手动输入。

修复浏览器页面在会话切换、布局变化和页面恢复时偶发闪烁、缩小或显示位置不正确的问题。导航重试成功后会清除已经失效的错误提示，下载提示仍会保留。


### 3.源码管理刷新和 Git 状态更一致

刷新源码管理后，已打开的提交详情会重新加载，不再停留在旧内容。完善 Git 检查点、工作树同步和 revision 校验，减少文件刚变化时列表、Diff 与实际仓库状态不一致，以及并发刷新覆盖新结果的问题。


### 4.验收角色提示词优化
AUTO 验收时，需求中明确要求但缺失或只完成一部分的项目会继续作为阻塞项，不会被误归为后续建议而提前判定通过。人工检查暂停的统计上报也已恢复。

### 5.其他体验优化

1.修复 Windows 10 无边框窗口阴影周围出现黑框的问题。
2.统一桌面端、官网和录屏页面的动画表现；运行中的侧栏状态继续保持呼吸提示。
3.修复用户反馈弹窗中关联会话较多时选择器溢出的问题。
4.优化 Git 历史、提交文件和分支读取范围，减少不必要的数据读取。
5.其他 UI 样式、构建发布和已知问题修复若干。
