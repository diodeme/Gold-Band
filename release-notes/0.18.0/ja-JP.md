## 機能の追加・変更

### 1.ファイルワークスペースでファイルを直接管理

右側ワークスペースのファイルツリーから、ファイルやフォルダーの作成、名前変更、削除を直接行えるようになりました。システムのファイルマネージャーへ切り替える必要はありません。

作成と名前変更はファイルツリー上で直接編集できます。削除時には確認が表示され、内容はシステムのごみ箱へ移動します。ファイルツリーにフォーカスがあるときは、`Ctrl+Z`（macOS では `Command+Z`）で直前の作成、名前変更、削除を元に戻せます。

![image.png](https://static.dion.blue/2026/09/20260930162214313.png)

### 2.ファイルと Diff を会話へ直接引用

入力欄の `@` メニューから、現在のワークスペースにあるファイルを参照・検索できるようになりました。ファイルを選択すると、現在の Agent に送るメッセージへファイル参照が追加されます。Workflow と AUTO の後続ノードにも同じ参照が渡されます。

![image.png](https://static.dion.blue/2026/09/20260930163805780.png)

ワークスペースのファイル、実行ディレクトリ、添付ファイル、ファイル変更からテキストを選択すると、該当行を直接引用できます。Diff 内の選択では、関連する変更ブロック全体が自動的に含まれ、ファイル見出しから Diff 全体を引用することもできます。引用にはファイルパス、行番号、変更元が保持されるため、Agent がコンテキストを正確に把握できます。

![image.png](https://static.dion.blue/2026/09/20260930162523931.png)

### 3.ソース管理から個別ファイルの変更を破棄

ソース管理のファイル操作に「変更を破棄」を追加しました。確認後、ステージ済みと未ステージの変更をまとめて `HEAD` に戻します。Git でまだ追跡されていない新規ファイルは削除されます。

> [!attention] 破棄した変更は復元できません
> この操作ではシステムのごみ箱へ移動しません。ファイルのローカル変更が不要であることを確認してから続行してください。

![image.png](https://static.dion.blue/2026/09/20260930162543785.png)

### 4.更新入口とインストールフローを再設計

新しいバージョンが見つかると、タイトルバーに「更新」ボタンが常に表示されます。クリックするとダイアログでリリースノートを確認し、ノート内の画像を拡大して、そのまま更新を開始できます。ダウンロード中は進捗が表示され、失敗時は再試行でき、完了後は再起動してインストールするよう案内されます。

![image.png](https://static.dion.blue/2026/09/20260930162647062.png)

インストール前に編集中のファイルを保存し、通常の終了処理に沿ってセッションを一時停止し、接続とバックグラウンドサービスを終了します。その後、ダウンロードした更新の署名とバージョンを検証してからインストールするため、作業状態の消失や誤ったパッケージのインストールを防ぎやすくなりました。

このリリースは通常更新です。クライアントは新しいバージョンを通知するだけで、ダウンロードとインストールは手動で開始するまで実行しません。

### 5.Agent 管理で npx キャッシュを対象指定して修復

npm/npx Agent のインストールキャッシュ不足によって診断が失敗した場合、Agent 管理に「キャッシュを修復」が表示されます。対象ディレクトリを確認すると、Gold Band は今回のエラーに関係する npx インストールディレクトリだけを削除し、Agent を自動的に再診断します。

npm キャッシュ全体、プロジェクトファイル、グローバルパッケージ、アカウント設定は削除されません。対象キャッシュを使用中の Agent は中断する可能性があるため、関連タスクを先に停止してください。

## エクスペリエンスの改善

### 1.右側ワークスペースがセッションの worktree に追従

ファイルの参照、編集、検索、ファイルリンク、`@` ファイルメニュー、ソース管理が、現在のセッションで実際に使用している worktree を一貫して参照するようになりました。別のノードや worktree に切り替えると右側ワークスペースも同期し、誤ってプロジェクトのメインディレクトリを読み込むことがなくなります。

過去のセッションの worktree が回収済みの場合は、利用不可の状態を明示します。「メインワークスペースを参照」を選択した場合にだけメインディレクトリへ切り替わり、自動でフォールバックしません。

### 2.ソース管理のパフォーマンスを改善し、表示を高速化

ソース管理の初回読み込み、バックグラウンド更新、コミットレビューを改善し、最初に開く際の待ち時間を短縮しました。リポジトリ情報とファイル一覧が先に表示され、行数統計は後から補完されます。ワークスペースのファイル検索では `.git` メタデータを除外し、一時的な Git ロックファイルによる不要な全体更新も発生しません。

ワークスペースのファイル変更後に状態更新が遅れる問題や、遅いリクエストが新しい結果を上書きする問題も修正しました。開いている Diff、検索条件、リポジトリ情報はバックグラウンドでの再確認中も維持されます。

### 3.その他の改善

1.ファイルワークスペースで SVG をネイティブ表示し、現在のファイルをシステムアプリで開けるようになりました。
2.Agent の各ターンにおけるファイル変更記録を改善し、バックグラウンド処理や worktree 外の変更も失われにくくしました。証拠が不完全な場合は明示されます。
3.起動時に現在の表示言語だけを読み込み、不要な読み取りと起動処理を削減しました。
4.Windows 10 でネイティブなサイズ変更後にウィンドウ枠が消える問題を修正しました。
5.メニュー操作後に省略テキストのツールチップが残る問題、トリガーが非表示になった後にツールチップがウィンドウ左上へ残る問題、ロールタグ削除後に入力欄のフォーカスが失われる問題を修正しました。
6.デフォルトチャネルでは利用できない「要件管理」入口を表示しないようにし、各言語に残っていた誤訳を修正しました。
