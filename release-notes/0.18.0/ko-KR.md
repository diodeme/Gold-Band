## 기능 추가 및 변경

### 1.파일 작업 영역에서 파일 직접 관리

이제 오른쪽 작업 영역의 파일 트리에서 파일이나 폴더를 만들고, 이름을 바꾸고, 삭제할 수 있습니다. 시스템 파일 관리자로 전환할 필요가 없습니다.

만들기와 이름 바꾸기는 파일 트리에서 바로 편집합니다. 삭제하기 전에는 확인을 요청하며, 항목은 시스템 휴지통으로 이동합니다. 파일 트리에 포커스가 있을 때 `Ctrl+Z`(macOS에서는 `Command+Z`)를 누르면 가장 최근의 만들기, 이름 바꾸기 또는 삭제 작업을 실행 취소할 수 있습니다.

![image.png](https://static.dion.blue/2026/09/20260930162214313.png)

### 2.파일과 Diff를 대화에 바로 인용

입력창의 `@` 메뉴에서 현재 작업 영역의 파일을 탐색하고 검색할 수 있습니다. 파일을 선택하면 현재 Agent에 보낼 메시지에 파일 참조가 추가되며, Workflow와 AUTO의 후속 노드에도 이 참조가 전달됩니다.

![image.png](https://static.dion.blue/2026/09/20260930163805780.png)

작업 영역 파일, 실행 디렉터리, 첨부 파일 또는 파일 변경 내역에서 텍스트를 선택하면 해당 줄을 바로 인용할 수 있습니다. Diff에서 내용을 선택하면 관련 변경 블록 전체가 자동으로 포함되며, 파일 제목에서 전체 Diff를 인용할 수도 있습니다. 인용에는 파일 경로, 줄 번호와 변경 출처가 유지되어 Agent가 컨텍스트를 정확하게 이해할 수 있습니다.

![image.png](https://static.dion.blue/2026/09/20260930162523931.png)

### 3.소스 제어에서 개별 파일 변경 사항 취소

소스 제어의 파일 작업에 “변경 사항 취소”가 추가되었습니다. 확인하면 스테이징된 변경 사항과 스테이징되지 않은 변경 사항이 모두 `HEAD`로 복원됩니다. Git에서 아직 추적하지 않는 새 파일은 삭제됩니다.

> [!attention] 취소한 변경 사항은 복구할 수 없습니다
> 이 작업은 파일을 시스템 휴지통으로 이동하지 않습니다. 해당 파일의 로컬 변경 사항이 더 이상 필요하지 않은지 확인한 후 계속하세요.

![image.png](https://static.dion.blue/2026/09/20260930162543785.png)

### 4.업데이트 진입점과 설치 흐름 재설계

새 버전이 발견되면 제목 표시줄에 “업데이트” 버튼이 계속 표시됩니다. 이 버튼을 누르면 대화 상자에서 릴리스 노트를 보고, 노트의 이미지를 확대하고, 바로 업데이트를 시작할 수 있습니다. 다운로드 중에는 진행률이 표시되고, 실패하면 다시 시도할 수 있으며, 완료되면 재시작하여 설치하라는 안내가 표시됩니다.

![image.png](https://static.dion.blue/2026/09/20260930162647062.png)

설치 전에 편집 중인 파일을 저장하고, 정상 종료 절차에 따라 세션을 일시 중지하고 연결과 백그라운드 서비스를 종료합니다. 그 후 다운로드한 업데이트의 서명과 버전을 검증한 뒤 설치하여 작업 상태가 손실되거나 잘못된 패키지가 설치될 위험을 줄였습니다.

이번 릴리스는 일반 업데이트입니다. 클라이언트는 새 버전을 알리기만 하며, 사용자가 수동으로 다운로드와 설치를 시작할 때까지 기다립니다.

### 5.Agent 관리에서 npx 캐시 선택 복구

npm/npx Agent가 불완전한 설치 캐시로 인해 진단에 실패하면 Agent 관리에 “캐시 복구”가 표시됩니다. 대상 디렉터리를 확인하면 Gold Band는 이번 오류와 관련된 npx 설치 디렉터리만 삭제하고 Agent를 자동으로 다시 검사합니다.

전체 npm 캐시, 프로젝트 파일, 전역 패키지 또는 계정 설정은 삭제하지 않습니다. 해당 캐시를 사용 중인 Agent가 중단될 수 있으므로 관련 작업을 먼저 중지하세요.

## 사용 경험 개선

### 1.오른쪽 작업 영역이 세션 worktree를 정확히 따름

파일 탐색, 편집, 검색, 파일 링크, `@` 파일 메뉴와 소스 제어가 현재 세션의 실제 worktree를 일관되게 사용합니다. 다른 노드나 worktree로 전환하면 오른쪽 작업 영역도 함께 전환되어 프로젝트 기본 디렉터리를 잘못 읽지 않습니다.

과거 세션의 worktree가 회수된 경우 사용할 수 없는 상태를 명확히 표시합니다. “기본 작업 영역 탐색”을 선택한 경우에만 기본 디렉터리로 전환하며 자동으로 대체하지 않습니다.

### 2.소스 제어 성능을 최적화하여 더 빠르게 열기

소스 제어의 초기 로딩, 백그라운드 새로 고침과 커밋 검토를 개선하여 처음 열 때의 대기 시간을 줄였습니다. 저장소 정보와 파일 목록이 먼저 표시되고 줄 통계는 나중에 채워집니다. 작업 영역 파일 검색은 `.git` 메타데이터를 건너뛰며, 일시적인 Git 잠금 파일도 더 이상 불필요한 전체 새로 고침을 일으키지 않습니다.

작업 영역 파일 변경 후 상태 업데이트가 늦어지거나 느린 요청이 새 결과를 덮어쓰는 문제도 수정했습니다. 열려 있는 Diff, 검색 조건과 저장소 정보는 백그라운드 조정 중에도 유지됩니다.

### 3.기타 개선 사항

1.파일 작업 영역에서 SVG를 기본 미리 보기로 표시하고 현재 파일을 시스템 앱으로 열 수 있습니다.
2.Agent 턴의 파일 변경 기록을 개선하여 백그라운드 처리 또는 worktree 외부의 변경 사항이 누락되지 않도록 했습니다. 증거가 불완전하면 이를 명확히 표시합니다.
3.시작할 때 현재 인터페이스 언어만 로드하여 불필요한 읽기와 시작 작업을 줄였습니다.
4.Windows 10에서 기본 크기 조정 후 창 테두리가 사라지는 문제를 수정했습니다.
5.메뉴 작업 후 잘린 텍스트의 툴팁이 계속 남는 문제, 트리거가 숨겨진 뒤 툴팁이 창 왼쪽 위에 남는 문제와 역할 태그를 제거한 뒤 입력창 포커스가 사라지는 문제를 수정했습니다.
6.기본 채널에서 사용할 수 없는 요구 사항 관리 항목을 더 이상 표시하지 않으며, 다국어 화면에 남아 있던 일부 오역을 수정했습니다.
