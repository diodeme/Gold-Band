## 功能新增/调整

### 1.文件工作区支持直接管理文件

现在可以在右侧工作区的文件树中直接新建文件或文件夹、重命名和删除条目，不需要切换到系统文件管理器。

新建和重命名会在文件树中直接编辑；删除前会要求确认，并将内容移入系统回收站或废纸篓。文件树获得焦点时，可以按 `Ctrl+Z`（macOS 为 `Command+Z`）撤销最近的创建、重命名或删除操作。

![image.png](https://static.dion.blue/2026/09/20260930162214313.png)


### 2.从文件与 Diff 直接引用到对话

输入框中的 `@` 菜单现在可以浏览和搜索当前工作空间的文件。选择文件后，会把文件引用加入本次消息，发送给当前 Agent；Workflow 和 AUTO 中的后续节点也能收到这些引用。

![image.png](https://static.dion.blue/2026/09/20260930163805780.png)

在工作空间文件、运行目录、附件或文件变更中选中文字，可以直接引用对应行；在 Diff 中选择内容时，会自动包含完整的相关变更块，也可以从文件标题处引用完整 Diff。引用会保留文件路径、行号和变更来源，方便 Agent 准确理解上下文。

![image.png](https://static.dion.blue/2026/09/20260930162523931.png)

### 3.源码管理支持放弃单个文件的更改

源码管理的文件操作中新增“放弃更改”。确认后会把已暂存和未暂存的内容一起还原到 `HEAD`；尚未纳入 Git 的新文件会被删除。

> [!attention] 放弃更改无法撤销
> 此操作不会进入系统回收站。请先确认不再需要该文件的本地改动。

![image.png](https://static.dion.blue/2026/09/20260930162543785.png)

### 4.更新入口和安装流程重新设计

发现新版本后，标题栏会持续显示“更新”按钮。点击后可以在弹窗中查看更新说明、放大说明中的图片，并直接开始更新；下载期间会显示进度，失败后可以重试，下载完成后会提示重启安装。

![image.png](https://static.dion.blue/2026/09/20260930162647062.png)



### 5.Agent 管理支持定向修复 npx 缓存

当 npm/npx Agent 因安装缓存缺失而诊断失败时，Agent 管理页会提供“修复缓存”。确认目标目录后，Gold Band 只清理本次错误涉及的 npx 安装目录，并自动重新检测 Agent。

修复不会清空整个 npm 缓存，也不会删除项目文件、全局安装包或账号配置。正在使用相关缓存的 Agent 可能中断，建议先停止相关任务。

## 体验优化

### 1.右侧工作区准确跟随会话工作树

文件浏览、编辑、搜索、文件链接、`@` 文件菜单和源码管理现在统一使用当前会话实际所在的工作树。切换到不同节点或 worktree 时，右侧工作区会同步切换，不会误读项目主目录。

如果历史会话的工作树已经被收回，会明确显示不可用状态；只有点击“浏览主工作区”后才会切换到主目录，不再静默回退。

### 2.源码管理性能优化，提升打开速度

优化源码管理的首批加载、后台刷新和提交审阅，减少首次打开时的等待。仓库信息和文件列表可以更早显示，行数统计随后补齐；工作空间文件搜索会跳过 `.git` 元数据，临时 Git 锁文件也不会再触发无意义的整页刷新。

修复工作区文件变化后状态未及时更新、慢请求覆盖新结果等问题。已打开的 Diff、搜索条件和仓库信息会在后台校准期间保持可用。

### 3.其他体验优化

1.文件工作区原生预览 SVG，并可用系统应用打开当前文件。
2.完善 Agent 本轮文件变更记录，后台处理或工作树之外的修改不再轻易丢失；证据不完整时会明确提示。
3.启动时只加载当前界面语言，减少不必要的读取和启动负担。
4.修复 Windows 10 原生缩放后窗口边框消失的问题。
5.修复菜单操作后截断文字提示层可能常驻、触发控件隐藏后提示层停在窗口左上角，以及移除角色标签后输入框失去焦点的问题。
6.默认渠道不再显示未启用的“需求管理”入口，并修正多语言界面的部分残留错译。
