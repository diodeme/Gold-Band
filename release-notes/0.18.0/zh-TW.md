## 功能新增/調整

### 1.檔案工作區支援直接管理檔案

現在可以直接在右側工作區的檔案樹建立檔案或資料夾、重新命名和刪除項目，不需要切換到系統檔案管理員。

建立和重新命名會直接在檔案樹中編輯；刪除前會要求確認，並將內容移至系統資源回收筒或垃圾桶。檔案樹取得焦點時，可以按 `Ctrl+Z`（macOS 為 `Command+Z`）復原最近的建立、重新命名或刪除操作。

![image.png](https://static.dion.blue/2026/09/20260930162214313.png)

### 2.從檔案與 Diff 直接引用到對話

輸入框中的 `@` 選單現在可以瀏覽和搜尋目前工作空間的檔案。選擇檔案後，會把檔案引用加入本次訊息並傳送給目前 Agent；Workflow 和 AUTO 中的後續節點也能收到這些引用。

![image.png](https://static.dion.blue/2026/09/20260930163805780.png)

在工作空間檔案、執行目錄、附件或檔案變更中選取文字，可以直接引用對應行；在 Diff 中選取內容時，會自動包含完整的相關變更區塊，也可以從檔案標題引用完整 Diff。引用會保留檔案路徑、行號和變更來源，方便 Agent 準確理解上下文。

![image.png](https://static.dion.blue/2026/09/20260930162523931.png)

### 3.原始碼管理支援放棄單一檔案的變更

原始碼管理的檔案操作中新增「放棄變更」。確認後會把已暫存和未暫存的內容一起還原到 `HEAD`；尚未納入 Git 的新檔案會被刪除。

> [!attention] 放棄變更無法復原
> 此操作不會進入系統資源回收筒。請先確認不再需要該檔案的本機變更。

![image.png](https://static.dion.blue/2026/09/20260930162543785.png)

### 4.重新設計更新入口和安裝流程

發現新版本後，標題列會持續顯示「更新」按鈕。點擊後可以在對話框中查看更新說明、放大說明中的圖片，並直接開始更新；下載期間會顯示進度，失敗後可以重試，下載完成後會提示重新啟動並安裝。

![image.png](https://static.dion.blue/2026/09/20260930162647062.png)

安裝現在會先儲存正在編輯的檔案，並按正常結束流程暫停工作階段、關閉連線和背景服務，再驗證已下載更新的簽章和版本後安裝，降低更新過程中遺失工作狀態或安裝錯誤套件的風險。

本版本為一般更新：用戶端只會提示新版本，等待你手動開始下載和安裝。

### 5.Agent 管理支援定向修復 npx 快取

當 npm/npx Agent 因安裝快取缺失而診斷失敗時，Agent 管理頁會提供「修復快取」。確認目標目錄後，Gold Band 只清理本次錯誤涉及的 npx 安裝目錄，並自動重新檢測 Agent。

修復不會清空整個 npm 快取，也不會刪除專案檔案、全域安裝套件或帳號設定。正在使用相關快取的 Agent 可能會中斷，建議先停止相關工作。

## 體驗最佳化

### 1.右側工作區準確跟隨工作階段 worktree

檔案瀏覽、編輯、搜尋、檔案連結、`@` 檔案選單和原始碼管理現在統一使用目前工作階段實際所在的 worktree。切換到不同節點或 worktree 時，右側工作區會同步切換，不會誤讀專案主目錄。

如果歷史工作階段的 worktree 已被回收，會明確顯示不可用狀態；只有點擊「瀏覽主工作區」後才會切換到主目錄，不再靜默回退。

### 2.原始碼管理效能最佳化，提升開啟速度

最佳化原始碼管理的首批載入、背景重新整理和提交審閱，減少首次開啟時的等待。儲存庫資訊和檔案清單可以更早顯示，行數統計隨後補齊；工作空間檔案搜尋會略過 `.git` 中繼資料，暫時性的 Git 鎖定檔案也不會再觸發無意義的整頁重新整理。

修復工作區檔案變更後狀態未及時更新、較慢請求覆蓋新結果等問題。已開啟的 Diff、搜尋條件和儲存庫資訊會在背景校準期間保持可用。

### 3.其他體驗最佳化

1.檔案工作區可原生預覽 SVG，並可使用系統應用程式開啟目前檔案。
2.完善 Agent 本輪檔案變更記錄，背景處理或 worktree 之外的修改不再輕易遺失；證據不完整時會明確提示。
3.啟動時只載入目前介面語言，減少不必要的讀取和啟動負擔。
4.修復 Windows 10 原生縮放後視窗邊框消失的問題。
5.修復選單操作後截斷文字提示層可能持續顯示、觸發控制項隱藏後提示層停在視窗左上角，以及移除角色標籤後輸入框失去焦點的問題。
6.預設渠道不再顯示尚未啟用的「需求管理」入口，並修正多語言介面的部分殘留誤譯。
