## 기능 추가 및 변경

### 1.Direct 세션의 백그라운드 메시지 수신과 상주 지원

Agent가 한 번의 응답을 마친 뒤에도 작업을 계속할 때(예: 예약 작업 실행, 백그라운드 하위 Agent 실행) Direct 세션이 이제 해당 응답, 도구 호출, 권한 확인, 질문을 계속 받습니다. 응답이 끝난 뒤에 사라지지 않습니다.

1.백그라운드에서 새 응답 본문이 도착하면 한 번 알림을 보냅니다. 같은 응답의 이어지는 내용으로는 다시 알리지 않습니다.
2.백그라운드에서 실행되는 동안 사이드바의 세션 아이콘이 깜박이고 시간 자리에 로딩 표시가 나타납니다. 세션 안에서는 Agent가 생각 중인 내용이나 호출 중인 도구를 볼 수 있습니다.
3.백그라운드 활동이 있으면 입력창에 중지 버튼이 표시되어 백그라운드 작업을 중지할 수 있습니다. 새 메시지 전송에는 영향이 없습니다.
4.백그라운드 도구가 수정한 파일은 가장 최근 턴의 파일 변경에 포함됩니다.

Direct 세션을 마우스 오른쪽 버튼으로 클릭하고 "세션 계속 유지"를 선택하면 제목 옆에 핀이 표시됩니다. 다시 오른쪽 클릭 후 "상주 해제"를 선택하면 해제됩니다.

살아 있는 Direct 세션이 8개 이하이면 모두 유지됩니다. 8개를 넘으면 6시간 넘게 유휴 상태인 세션이 회수되고, 20개를 넘으면 가장 오래 활동이 없던 세션이 먼저 회수됩니다. 상주 중이거나 실행 중이거나 권한·질문 처리를 기다리는 세션은 회수되지 않습니다.

> [!WARNING]
> 상주는 앱이 실행 중일 때만 유효하며, 앱을 다시 시작해도 상주 세션이 자동으로 시작되지 않습니다. 상주하지 않은 세션이 회수되면 그 안의 예약 작업이 중단될 수 있습니다. 백그라운드 작업 중지는 Agent에 취소 요청을 보내는 것일 뿐이며, 예약 작업 삭제 여부는 Agent가 결정합니다.

### 2.Markdown에서 Mermaid 다이어그램과 GitHub 알림 지원

대화와 파일 미리보기의 ` ```mermaid ` 코드 블록이 이제 다이어그램으로 렌더링되며, 색상은 현재 테마를 따릅니다. 다이어그램을 클릭하면 오른쪽 작업 영역에서 열리며 확대/축소, 이동, PNG로 복사 또는 저장할 수 있습니다.

대화와 파일 미리보기에서는 GitHub의 다섯 가지 알림 `[!NOTE]`, `[!TIP]`, `[!IMPORTANT]`, `[!WARNING]`, `[!CAUTION]`도 지원합니다.

### 3.웹 이미지는 신뢰하는 도메인에서만 불러오기

문서나 Agent 응답이 클라이언트로 하여금 임의의 서버에 요청을 보내지 않도록, Markdown의 웹 이미지는 이제 신뢰하는 도메인의 것만 자동으로 불러옵니다.

1.대화: 신뢰하지 않는 이미지는 자리 표시자로 표시되며, "불러오기"를 클릭하면 해당 도메인을 신뢰하고 이미지를 표시합니다.
2.파일 미리보기: 신뢰하지 않는 이미지는 링크로 유지되며, 상단 안내에서 문서의 모든 도메인을 한 번에 신뢰할 수 있습니다.
3."설정 → 고급 → 신뢰하는 이미지 도메인"에서 신뢰한 도메인을 확인하고 제거할 수 있습니다.

### 4.컨텍스트 압축 요약 보기

Agent가 컨텍스트 압축을 마치고 텍스트 요약을 반환하면 압축 기록에 "요약 보기"가 표시됩니다. 클릭하면 오른쪽 작업 영역에서 요약이 열리며, 기본적으로 Markdown으로 표시되고 소스 보기로 전환하거나 복사할 수 있습니다.

### 5.모델별 설정 가져오기

워크플로 노드, AUTO 설정, 홈 입력창 또는 세션에서 아직 사용하지 않은 모델을 선택하면 "아직 이 모델의 설정을 가져오지 않았습니다"와 "모델 설정 가져오기" 버튼이 표시됩니다. 클릭하면 해당 모델로 Agent를 한 번 실행해 실제 선택 가능한 설정을 읽어 옵니다. 메시지를 보내지 않으며 작업도 만들지 않습니다.

클릭하지 않아도 편집, 저장, 작업 시작을 계속할 수 있습니다. 기존 모델 설정이 다른 모델의 설정 때문에 잘려 나가지 않으며, Agent 백그라운드 진단이 실패해도 이미 가져온 모델 설정이 지워지지 않습니다.

### 6.릴리스 노트를 GitHub 형식으로 표시하고 도움말 메뉴에서 확인

업데이트 대화 상자의 설명이 이제 GitHub Release와 같은 방식으로 표시되며 줄바꿈과 알림을 지원합니다. "도움말 → 릴리스 노트"가 추가되어 현재 버전의 업데이트 내용을 언제든지 확인할 수 있습니다.

### 7.워크플로 그래프 레이아웃 개편

워크플로 편집기와 실행 그래프에 새 자동 레이아웃을 적용해 노드와 연결선 배치가 더 명확해졌습니다. AI-DYNAMIC이 동적으로 만든 그룹은 중첩된 틀로 표시되며, 레이아웃 계산이 오래 걸리면 로딩 상태가 표시됩니다.


## 사용 경험 개선

### 1.AUTO 결과물은 반드시 검수를 통과해야 완료

AUTO 개발이 끝나면 검수 노드가 원래 요구 사항과 대조해 한꺼번에 확인합니다. 검수를 통과하지 못하면 수정을 배정하고 다시 검수하며, 통과한 경우에만 종료됩니다. 검수는 원래 요구 사항만을 근거로 하며, 계획에서 요구 사항 내용을 제외하면 차단 문제로 처리됩니다. 수정된 기존 테스트는 원래 버전으로 다시 검증해야 합니다.

Agent가 제출하는 긴 요약과 작업 설명은 이제 파일로 전달되어 출력 형식 오류로 인한 재시도가 줄었습니다. AUTO가 일시 중지되면 알림 표시줄에 구체적인 오류 제목이 표시됩니다.

### 2.Claude 및 Codex 연동 업그레이드

Claude ACP를 `0.87.0`, Codex ACP를 `2.1.1`로 업그레이드했습니다.

1.세션에 컨텍스트 압축 상태, 소요 시간, 압축 전 사용량이 표시됩니다.
2.Codex가 실행한 명령의 출력이 도구 상세 정보에 계속 누적되며 최대 256,000자까지 보관됩니다.
3.Claude 질문에 대한 사용자 지정 답변을 정상적으로 제출할 수 있습니다.
4.Agent가 다시 로그인해야 할 때 명확하게 안내합니다. 로그인한 뒤 직접 다시 보내면 됩니다.

### 3.더 안정적인 세션

1.세션에 다시 들어갈 때 로딩 상태가 반복해서 표시되거나 오래된 내용이 먼저 표시되지 않습니다.
2.디스크 공간 부족이나 쓰기 권한 없음과 같은 실행 오류가 즉시 표시되며, 입력창이 계속 대기 상태로 남지 않습니다. 결과가 반환되지 않은 도구에는 "결과 미확인"이 표시되고 기존 응답과 초안은 유지됩니다.
3.응답을 중지한 후 세션이 항상 현재 턴을 올바르게 종료하며 더 이상 "중지 중"에 머무르지 않습니다.

### 4.더 정확한 파일 변경 기록

1.Claude 등의 Agent가 같은 파일을 조각 단위로 여러 번 편집할 때 턴 전체 변경이 불완전으로 표시되던 문제를 수정했습니다.
2.Cursor가 새로 만든 파일이 수정으로 기록되고 내용에 Diff 표시가 섞이던 문제를 수정했습니다.
3.파일 변경 행에 파일 이름, 디렉터리, 추가/삭제 줄 수가 일관되게 표시되며, 여러 번 편집된 파일에는 편집 횟수도 표시됩니다.

### 5.기타 개선 사항

1.이미지 미리보기 통합: 파일 이미지와 세션 이미지 모두 마우스 휠로 바로 확대/축소할 수 있고, 처음 열 때 창에 맞춰 표시되며, 원본 크기를 보여 주는 "100%" 버튼을 제공합니다.
2.내장 브라우저에서 로컬 HTML을 열 때 상위 디렉터리의 리소스를 정상적으로 불러옵니다. 허용 범위 밖의 디렉터리에 접근하면 안내에서 "접근 허용"을 선택할 수 있습니다.
3.대화의 제목 계층이 더 명확해지고 스트리밍 출력 중에도 제목 간격이 유지됩니다. "릴리스 노트"는 도움말 메뉴 끝으로 이동했습니다.
4.서로 다른 채널의 클라이언트를 함께 설치한 경우, 하나를 설치하거나 업데이트하면 실행 중인 다른 클라이언트가 종료되던 문제를 수정했습니다.
5.ACP Registry와 Agent 카탈로그를 업데이트했습니다.
