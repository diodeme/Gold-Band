## 功能新增/调整

### 1.Direct 会话支持后台消息与常驻

Agent 在一轮回复结束后继续工作时（例如触发定时任务、在后台运行子 Agent），Direct 会话现在会继续接收它的回复、工具调用、权限确认和问题，不会在回复结束后丢失。（目前主要支持claude code）

![image.png](https://static.dion.blue/2026/10/20261010151334594.png)

1.后台出现新的回复正文时会提醒一次；同一条回复的后续内容不会重复提醒。
2.后台有活动时，输入框会显示停止按钮，可以停止后台工作；发送新消息不受影响。

在 Direct 会话上右键选择「常驻会话」，标题旁会显示图钉，再次右键可以「解除常驻」。也可以点击会话顶部「原始帧」左侧的图钉按钮开启或解除常驻。
![企业微信截图_17916164711387.png](https://static.dion.blue/2026/10/%E4%BC%81%E4%B8%9A%E5%BE%AE%E4%BF%A1%E6%88%AA%E5%9B%BE_17916164711387.png)

![image.png](https://static.dion.blue/2026/10/20261012140125448.png)

Direct、工作流和 AUTO 会话使用同一套回收规则：空闲超过 10 分钟的会话会被回收；空闲会话超过 8 个时，会先回收最久未活动的会话。常驻、正在执行或等待你处理权限和问题的会话不会被回收。Agent 有定时任务等需要长时间运行的工作时，请开启常驻。

> [!WARNING]
> 1.常驻只在应用运行期间有效，重启应用后不会自动启动常驻会话。未常驻的会话被回收后，其中的定时任务可能中断。停止后台工作只是向 Agent 发送取消请求，是否删除定时任务由 Agent 决定。
> 2.由于acp目前没有后台任务是否完成的标识，所以后台任务完成判断取决于 没有正在运行的后台活动 & 10s内没有新活动产生，所以可能造成后台任务已终止，但是10s会话依旧保持活跃态的问题。


### 2.Markdown 支持 Mermaid 图表和 GitHub 提示块

对话和文件预览中的 ` ```mermaid ` 代码块现在会渲染成图表，颜色跟随当前主题。点击图表会在右侧工作区打开，可以缩放、拖动，并复制或保存为 PNG。

![image.png](https://static.dion.blue/2026/10/20261010151001399.png)


对话和文件预览也支持 GitHub 的五种提示块：`[!NOTE]`、`[!TIP]`、`[!IMPORTANT]`、`[!WARNING]` 和 `[!CAUTION]`。

![企业微信截图_17916161364315.png](https://static.dion.blue/2026/10/%E4%BC%81%E4%B8%9A%E5%BE%AE%E4%BF%A1%E6%88%AA%E5%9B%BE_17916161364315.png)


### 3.网络图片只从受信任的域名加载

为避免文档或 Agent 回复让客户端向任意服务器发送请求，Markdown 中的网络图片现在只会自动加载受信任域名的内容。

1.对话中：未信任的图片显示占位，点击「加载」后信任该域名并显示图片。
![企业微信截图_17916165045640.png](https://static.dion.blue/2026/10/%E4%BC%81%E4%B8%9A%E5%BE%AE%E4%BF%A1%E6%88%AA%E5%9B%BE_17916165045640.png)
![企业微信截图_17916165149409.png](https://static.dion.blue/2026/10/%E4%BC%81%E4%B8%9A%E5%BE%AE%E4%BF%A1%E6%88%AA%E5%9B%BE_17916165149409.png)

2.文件预览中：未信任的图片保持为链接，可以通过顶部提示一次性信任文档中的全部域名。
![企业微信截图_17916165865322.png](https://static.dion.blue/2026/10/%E4%BC%81%E4%B8%9A%E5%BE%AE%E4%BF%A1%E6%88%AA%E5%9B%BE_17916165865322.png)

3.在「设置 → 高级 → 受信任的图片域名」中可以查看和移除已信任的域名。

### 4.查看上下文压缩摘要

Agent 完成上下文压缩并返回文本摘要时，压缩记录中会显示「查看摘要」(如果agent返回了)。点击后在右侧工作区打开摘要，默认按 Markdown 显示，也可以切换为源码并复制。
![企业微信截图_17916167016992.png](https://static.dion.blue/2026/10/%E4%BC%81%E4%B8%9A%E5%BE%AE%E4%BF%A1%E6%88%AA%E5%9B%BE_17916167016992.png)


### 5.按模型获取配置

在工作流节点、AUTO 设置、主页输入框或会话中选择一个尚未用过的模型时，会显示「尚未获取此模型的配置」和「获取模型配置」按钮。点击后会用该模型启动一次 Agent 读取真实的可选配置，不发送任何消息，也不会创建任务。

![企业微信截图_17916167706477.png](https://static.dion.blue/2026/10/%E4%BC%81%E4%B8%9A%E5%BE%AE%E4%BF%A1%E6%88%AA%E5%9B%BE_17916167706477.png)


不点击也可以继续编辑、保存和发起任务。不支持的配置会在会话发起时降级为不指定。

### 6.工作流图布局重新设计

工作流编辑器和运行图改用新的自动布局，节点和连线排列更清晰。AI-DYNAMIC 动态创建的分组会以嵌套框显示，布局较慢时会显示加载状态。


## 体验优化

### 1.AUTO 交付必须经过验收

AUTO 开发完成后，必须交给验收节点对照原始需求统一检查；验收不通过会继续安排修复并再次验收，只有通过后才会结束。验收以原始需求为唯一依据，计划中排除了需求内容会被视为阻塞问题，被修改的已有测试需要按原版本重新验证。

Agent 提交的较长总结和任务说明改为通过文件交接，减少因输出格式错误导致的重试。AUTO 暂停时，提示条会显示具体的错误标题。

### 2.Claude 和 Codex 适配升级

Claude ACP 升级到 `0.87.0`，Codex ACP 升级到 `2.1.1`。

1.会话中显示上下文压缩的状态、耗时和压缩前用量。
2.Codex 执行命令的输出会持续累积到工具详情中，最多保留 256,000 个字符。
3.Claude 提问中的自定义答案可以正常提交。
4.Agent 需要重新登录时会明确提示，登录后手动重新发送即可。

### 3.会话更稳定

1.重新进入会话时不再反复显示加载状态，也不会先显示旧内容。
2.磁盘已满或没有写入权限等执行错误会立即显示，输入框不再一直处于等待状态；没有返回结果的工具显示「结果未确认」，已有回复和草稿会保留。
3.停止回复后，会话总能正确结束当前轮次，不再停在「停止中」。

### 4.文件变更记录更准确

1.修复 Claude 等 Agent 以片段方式多次编辑同一文件时，整轮变更被标记为不完整的问题。
2.修复 Cursor 新建的文件被记录为修改、内容中混入 Diff 标记的问题。
3.文件变更行统一显示文件名、目录和增删行数，多次编辑的文件会显示编辑次数。

### 5.降低资源占用

1.空闲会话会按上面的规则及时回收，不再长期占用 Agent 进程。
2.内置浏览器隐藏超过 1 小时后会释放页面，再次打开时按原地址重新加载。
3.已安装过的 npx Agent 启动时直接运行，省去常驻的 npx 包装进程。
4.会话输出回复时，侧栏不再跟着整体刷新。

### 6.其他体验优化

1.对话和文档中的 Markdown 表格会占满正文宽度并自动换行，长链接和代码不再撑宽表格。
2.图片预览统一：文件图片和会话图片都支持直接滚轮缩放，首次打开自动适应窗口，并提供「100%」原始尺寸按钮。
3.内置浏览器打开本地 HTML 时，可以正常加载上级目录中的资源；访问授权范围外的目录时，可以在提示中选择「允许访问」。
4.对话中的标题层级更清晰，流式输出时标题间距不再丢失；「更新日志」移到帮助菜单末尾。
5.修复同时安装不同渠道的客户端时，安装或更新其中一个会关闭另一个正在运行的客户端。
6.更新 ACP Registry 与 Agent 目录。
