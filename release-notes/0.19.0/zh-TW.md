## 功能新增/調整

### 1.Direct 對話支援背景訊息與常駐

Agent 在一輪回覆結束後繼續工作時（例如觸發排程任務、在背景執行子 Agent），Direct 對話現在會繼續接收它的回覆、工具呼叫、權限確認和問題，不會在回覆結束後遺失。（目前主要支援 Claude Code）

![image.png](https://static.dion.blue/2026/10/20261010151334594.png)

1.背景出現新的回覆正文時會提醒一次；同一則回覆的後續內容不會重複提醒。
2.背景有活動時，輸入框會顯示停止按鈕，可以停止背景工作；傳送新訊息不受影響。

在 Direct 對話上按右鍵選擇「常駐對話」，標題旁會顯示圖釘，再次按右鍵可以「解除常駐」。也可以點選對話頂部「原始幀」左側的圖釘按鈕開啟或解除常駐。
![企业微信截图_17916164711387.png](https://static.dion.blue/2026/10/%E4%BC%81%E4%B8%9A%E5%BE%AE%E4%BF%A1%E6%88%AA%E5%9B%BE_17916164711387.png)

![image.png](https://static.dion.blue/2026/10/20261012140125448.png)

Direct、工作流程和 AUTO 對話使用同一套回收規則：閒置超過 10 分鐘的對話會被回收；閒置對話超過 8 個時，會先回收最久未活動的對話。常駐、正在執行或等待你處理權限和問題的對話不會被回收。Agent 有排程任務等需要長時間執行的工作時，請開啟常駐。

> [!WARNING]
> 1.常駐只在應用程式執行期間有效，重新啟動應用程式後不會自動啟動常駐對話。未常駐的對話被回收後，其中的排程任務可能中斷。停止背景工作只是向 Agent 傳送取消請求，是否刪除排程任務由 Agent 決定。
> 2.由於 ACP 目前沒有標示背景任務是否完成，背景任務是否結束取決於「沒有正在執行的背景活動，且 10 秒內沒有新活動」。因此背景任務已經終止後，對話可能仍會保持活動狀態 10 秒。


### 2.Markdown 支援 Mermaid 圖表和 GitHub 提示區塊

對話和檔案預覽中的 ` ```mermaid ` 程式碼區塊現在會渲染成圖表，顏色跟隨目前主題。點選圖表會在右側工作區開啟，可以縮放、拖曳，並複製或儲存為 PNG。

![image.png](https://static.dion.blue/2026/10/20261010151001399.png)


對話和檔案預覽也支援 GitHub 的五種提示區塊：`[!NOTE]`、`[!TIP]`、`[!IMPORTANT]`、`[!WARNING]` 和 `[!CAUTION]`。

![企业微信截图_17916161364315.png](https://static.dion.blue/2026/10/%E4%BC%81%E4%B8%9A%E5%BE%AE%E4%BF%A1%E6%88%AA%E5%9B%BE_17916161364315.png)


### 3.網路圖片只從受信任的網域載入

為避免文件或 Agent 回覆讓用戶端向任意伺服器傳送請求，Markdown 中的網路圖片現在只會自動載入受信任網域的內容。

1.對話中：未信任的圖片顯示預留位置，點選「載入」後信任該網域並顯示圖片。
![企业微信截图_17916165045640.png](https://static.dion.blue/2026/10/%E4%BC%81%E4%B8%9A%E5%BE%AE%E4%BF%A1%E6%88%AA%E5%9B%BE_17916165045640.png)
![企业微信截图_17916165149409.png](https://static.dion.blue/2026/10/%E4%BC%81%E4%B8%9A%E5%BE%AE%E4%BF%A1%E6%88%AA%E5%9B%BE_17916165149409.png)

2.檔案預覽中：未信任的圖片保持為連結，可以透過頂部提示一次信任文件中的全部網域。
![企业微信截图_17916165865322.png](https://static.dion.blue/2026/10/%E4%BC%81%E4%B8%9A%E5%BE%AE%E4%BF%A1%E6%88%AA%E5%9B%BE_17916165865322.png)

3.在「設定 → 進階 → 受信任的圖片網域」中可以查看和移除已信任的網域。

### 4.查看上下文壓縮摘要

Agent 完成上下文壓縮並回傳文字摘要時，壓縮紀錄中會顯示「查看摘要」（需 Agent 有回傳摘要）。點選後在右側工作區開啟摘要，預設以 Markdown 顯示，也可以切換為原始碼並複製。
![企业微信截图_17916167016992.png](https://static.dion.blue/2026/10/%E4%BC%81%E4%B8%9A%E5%BE%AE%E4%BF%A1%E6%88%AA%E5%9B%BE_17916167016992.png)


### 5.依模型取得設定

在工作流程節點、AUTO 設定、首頁輸入框或對話中選擇一個尚未用過的模型時，會顯示「尚未取得此模型的設定」和「取得模型設定」按鈕。點選後會用該模型啟動一次 Agent 讀取真實的可選設定，不傳送任何訊息，也不會建立任務。

![企业微信截图_17916167706477.png](https://static.dion.blue/2026/10/%E4%BC%81%E4%B8%9A%E5%BE%AE%E4%BF%A1%E6%88%AA%E5%9B%BE_17916167706477.png)


不點選也可以繼續編輯、儲存和發起任務。不支援的設定會在對話發起時降級為不指定。

### 6.工作流程圖版面重新設計

工作流程編輯器和執行圖改用新的自動版面配置，節點和連線排列更清晰。AI-DYNAMIC 動態建立的群組會以巢狀框顯示，版面配置較慢時會顯示載入狀態。


## 體驗最佳化

### 1.AUTO 交付必須經過驗收

AUTO 開發完成後，必須交給驗收節點對照原始需求統一檢查；驗收不通過會繼續安排修復並再次驗收，只有通過後才會結束。驗收以原始需求為唯一依據，計畫中排除了需求內容會被視為阻塞問題，被修改的既有測試需要依原版本重新驗證。

Agent 提交的較長總結和任務說明改為透過檔案交接，減少因輸出格式錯誤導致的重試。AUTO 暫停時，提示列會顯示具體的錯誤標題。

### 2.Claude 和 Codex 介接升級

Claude ACP 升級到 `0.87.0`，Codex ACP 升級到 `2.1.1`。

1.對話中顯示上下文壓縮的狀態、耗時和壓縮前用量。
2.Codex 執行命令的輸出會持續累積到工具詳情中，最多保留 256,000 個字元。
3.Claude 提問中的自訂答案可以正常提交。
4.Agent 需要重新登入時會明確提示，登入後手動重新傳送即可。

### 3.對話更穩定

1.重新進入對話時不再反覆顯示載入狀態，也不會先顯示舊內容。
2.磁碟已滿或沒有寫入權限等執行錯誤會立即顯示，輸入框不再一直處於等待狀態；沒有回傳結果的工具顯示「結果未確認」，既有回覆和草稿會保留。
3.停止回覆後，對話總能正確結束目前輪次，不再停在「正在停止」。

### 4.檔案變更紀錄更準確

1.修正 Claude 等 Agent 以片段方式多次編輯同一檔案時，整輪變更被標記為不完整的問題。
2.修正 Cursor 新建的檔案被記錄為修改、內容中混入 Diff 標記的問題。
3.檔案變更列統一顯示檔名、目錄和增刪行數，多次編輯的檔案會顯示編輯次數。

### 5.降低資源占用

1.閒置對話會依上述規則及時回收，不再長期占用 Agent 程序。
2.內建瀏覽器隱藏超過 1 小時後會釋放頁面，再次開啟時依原網址重新載入。
3.已安裝過的 npx Agent 啟動時直接執行，省去常駐的 npx 包裝程序。
4.對話輸出回覆時，側欄不再跟著整體重新整理。

### 6.其他體驗最佳化

1.對話和文件中的 Markdown 表格會占滿正文寬度並自動換行，長連結和程式碼不再撐寬表格。
2.圖片預覽統一：檔案圖片和對話圖片都支援直接以滾輪縮放，首次開啟自動適應視窗，並提供「100%」原始尺寸按鈕。
3.內建瀏覽器開啟本機 HTML 時，可以正常載入上層目錄中的資源；存取授權範圍外的目錄時，可以在提示中選擇「允許存取」。
4.對話中的標題層級更清晰，串流輸出時標題間距不再遺失；「更新日誌」移到說明選單末尾。
5.修正同時安裝不同通道的用戶端時，安裝或更新其中一個會關閉另一個正在執行的用戶端。
6.更新 ACP Registry 與 Agent 目錄。
