## エクスペリエンスの改善

### 1.Direct のバックグラウンド停止の修正

1.スケジュールタスクで Agent が起動し、バックグラウンドで質問が表示されたときに、停止をクリックしても何も反応しない問題を修正しました。停止はバックグラウンドの作業に正しく作用するようになり、待機中の権限確認は「キャンセル済み」として記録され、待機中の質問には「キャンセル」が返されるため、セッションが待機状態のまま固まることはなくなりました。
2.返信の実行中に届いた権限確認や質問は、そのターンの終了とともに正しく片付けられるようになり、停止後もセッションに残り続けなくなりました。処理済みのやり取りが、新しいライブ内容によって保留状態に巻き戻されることもなくなりました。

### 2.バックグラウンドの活動状態が固まらなくなりました

一部の Agent は停止後にツールの終了イベントを送らないため、サイドバーがずっと実行中と表示され、停止ボタンが常駐し、常駐セッションも回収されないままになっていました。ツールは所属ターンの終了またはバックグラウンド停止のタイミングで正しく清算され、10 秒活動がないとアイドルに戻るようになりました。

### 3.狭いペインでのモデルメニューの修正

会話ペインが狭いとき、モデルと思考の強度のサブメニューがウィンドウの左端に押し出され、サイドバーを覆っていました。スペースがない場合はメインメニュー内でその場に展開し（クリックまたは方向キーで操作）、十分なスペースがある場合は従来どおりホバー時のサイドポップアップになります。

### 4.その他の改善

1.ACP Registry のスナップショットと Agent カタログを更新しました。
