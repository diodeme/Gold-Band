## 사용 경험 개선

### 1.Direct 백그라운드 중지 수정

1.예약 작업으로 Agent가 깨어난 뒤 백그라운드에서 질문이 표시되었을 때 중지를 클릭해도 아무 반응이 없던 문제를 수정했습니다. 이제 중지가 백그라운드 작업에 올바르게 작동하며, 대기 중인 권한 확인은 "취소됨"으로 기록되고 대기 중인 질문은 "취소"로 응답되어 세션이 더 이상 대기 상태에 갇히지 않습니다.
2.응답이 실행되는 동안 도착한 권한 확인과 질문은 이제 해당 턴이 끝날 때 함께 정리되어, 중지 후에도 세션에 계속 남지 않습니다. 이미 처리된 상호작용이 새로 들어오는 실시간 내용 때문에 대기 상태로 되돌려지는 일도 없어졌습니다.

### 2.백그라운드 활동 상태가 더 이상 멈추지 않음

일부 Agent는 중지 후 도구의 종료 이벤트를 보내지 않아 사이드바에 세션이 계속 실행 중으로 표시되고, 중지 버튼이 계속 떠 있었으며, 상주 세션도 회수되지 않았습니다. 이제 도구는 소속 턴이 끝나거나 백그라운드 작업이 중지될 때 올바르게 정리되고, 10초 동안 활동이 없으면 유휴 상태로 돌아갑니다.

### 3.좁은 패널에서의 모델 메뉴 수정

대화 패널이 좁을 때 모델과 추론 강도의 하위 메뉴가 창의 왼쪽 끝으로 밀려나 사이드바를 덮었던 문제를 수정했습니다. 공간이 없으면 주 메뉴 안에서 그 자리에 펼쳐지고(클릭 또는 방향키로 조작), 공간이 충분하면 기존처럼 마우스를 올렸을 때 옆으로 펼쳐집니다.

### 4.기타 개선 사항
