## 體驗最佳化

### 1.Direct 背景停止修復

1.修正排程任務喚醒後 Agent 在背景彈出問題時，點選停止沒有任何反應的問題。停止現在會正確作用於背景工作，等待中的權限確認會以「已取消」記錄，等待中的問題會以「取消」回覆，對話不會繼續卡在等待。
2.回覆進行中收到的權限確認和問題，現在會正確跟隨本輪結束收起，停止後不再一直掛在對話裡；已處理的互動也不會再被新的即時內容回滾成待處理狀態。

### 2.背景活動狀態不再卡住

此前部分 Agent 停止後不會補發工具的結束事件，導致側欄一直顯示對話活動中、停止按鈕常駐，常駐對話也永遠不會被回收。現在工具會在所屬輪次結束或背景停止時正確結算，10 秒無活動後恢復閒置。

### 3.窄面板下的模型選單修復

會話欄較窄時，模型和思考強度的二級選單此前會被擠到視窗最左邊並蓋住側欄。現在放不下時改為在主選單內原地展開（點選或按方向鍵操作），空間足夠時仍保持懸停側彈。

### 4.其他體驗最佳化

1.更新 ACP Registry 快照與 Agent 目錄。
