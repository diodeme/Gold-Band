## 기능 추가/변경

### 1.Feishu / Lark 원격 개입 지원

WeCom에 더해 이제 Feishu / Lark에서도 작업을 멈추게 한 권한 요청, 추가 질문, 수동 확인을 처리하고 Run 및 턴 종료 알림을 받을 수 있습니다.

1. "설정 → 일반 → IM 원격 개입 및 알림"을 열고 "Feishu / Lark"를 펼친 다음 "스캔하여 연결"을 클릭합니다.
2. 필요한 권한을 확인하고 "동의하고 QR 코드 생성"을 클릭한 뒤 휴대폰의 Feishu / Lark로 스캔합니다. 기존 Feishu / Lark 앱을 선택하거나 새 앱을 만들 수 있습니다.
3. 승인이 끝나면 Feishu / Lark에서 봇에게 메시지를 한 번 보내 1:1 개인 채팅을 바인딩합니다.
4. 작업에 조치가 필요하면 Feishu / Lark로 조작 가능한 카드가 전송됩니다. 카드에는 ID, 노드, 작업, 워크스페이스가 표시되며 권한 허용·거부, 추가 질문 답변(단일 선택, 다중 선택, 사용자 지정 답변, 텍스트), 수동 확인의 성공·실패 판정을 할 수 있습니다.

제출하면 카드에 답변이 남고 컨트롤은 비활성화됩니다. 데스크톱이나 WeCom에서 이미 처리한 요청은 처리한 곳이 표시됩니다. 중지, 시간 초과 등으로 종료된 요청은 "취소됨"으로 표시되며 거부로 표시되지 않습니다. 제출 처리가 지연되어 최종적으로 수락되지 않은 경우 봇이 별도 메시지로 이유를 알려 줍니다.

"구성 메뉴"에서 수신 계정 재바인딩, Feishu / Lark 앱 변경, 재승인, 구성 삭제를 할 수 있습니다.

> [!NOTE]
> 봇 하나는 기기 한 대에만 연결됩니다. 현재는 1:1 개인 채팅만 지원하며, Feishu / Lark 카드의 추가 질문은 최대 5개입니다. 이를 초과하는 요청은 데스크톱에서 처리하세요. 이름 읽기 권한은 선택 사항이며, 허용하지 않으면 수신 계정이 "1:1 채팅 바인딩됨"으로 표시됩니다.

> [!WARNING]
> 업그레이드 후 IM 데이터가 새 형식으로 마이그레이션되어 이전 버전 클라이언트에서는 더 이상 읽을 수 없습니다. 다운그레이드하려면 먼저 백업을 복원해야 합니다. 업그레이드 전에 전송되어 아직 처리되지 않은 WeCom 카드는 무효가 되므로 데스크톱에서 처리하세요.

### 2.대기 중 메시지에 지금 보내기와 자동 전송 추가

Agent가 답변하는 동안 대기열에 넣은 메시지의 전송 시점을 더 유연하게 제어할 수 있습니다.

1. "지금 보내기": 대기 중인 메시지를 바로 보냅니다. 답변이 진행 중이면 현재 답변을 중지할지 먼저 확인합니다. "다시 묻지 않기"를 선택하면 더 이상 확인하지 않으며, "설정 → 고급 → 대기 중"에서 다시 켤 수 있습니다.
2. "자동 전송" 스위치: 켜면 각 턴의 답변이 끝난 뒤 순서대로 자동 전송합니다. 끄면 메시지는 대기열에 남고, 하나씩 "지금 보내기"로 보냅니다.
3. 세션을 중지했거나 이전 전송이 실패하면 대기열에 일시 중지 상태와 이유가 표시됩니다. "재개"를 클릭하면 자동 전송을 계속합니다.
4. "더 보기"에서 대기열을 비울 수 있습니다.

### 3.임시 보관함 추가

입력창 도구 모음에 "임시 보관함"이 추가되었습니다. "임시 보관함에 저장"으로 입력 중인 내용을 보관해 두었다가 나중에 "입력창으로 가져오기"로 이어서 편집할 수 있습니다. 임시 저장 내용은 현재 세션에만 저장되고 자동으로 전송되지 않으며, 세션당 최대 20개까지 보관합니다.

### 4.Claude 네이티브 하위 Agent 지원

Claude ACP `0.90.0` 이상을 사용하면 Gold Band가 Claude가 보고하는 하위 Agent 상태를 읽어 실행 중, 상호작용 대기, 완료, 중단, 실패를 정확하게 표시합니다. 메인 턴이 끝났다는 이유만으로 하위 Agent가 중단으로 표시되지 않습니다.

1. 하위 Agent가 실행 중이면 입력창 위에 실행 중인 하위 Agent 요약이 표시되며, 클릭하면 오른쪽 워크스페이스에서 전체 기록을 볼 수 있습니다.
2. 메인 턴이 끝난 뒤에도 하위 Agent가 백그라운드에서 실행 중이거나 권한을 기다리는 동안에는 입력창에 "중지" 버튼이 유지됩니다.
3. 세션에 백그라운드 작업이 생기면 Token 사용량 툴팁에 "백그라운드 실행으로 사용된 양은 포함되지 않습니다"가 표시됩니다.

> [!IMPORTANT]
> Claude ACP가 `0.90.0`으로 업그레이드되었습니다. 버전이 너무 오래되면 업그레이드 안내가 표시되며, Gold Band가 설치 구성을 자동으로 변경하지는 않습니다.

### 5.푸시 전 대상 확인

소스 제어에서 브랜치를 푸시하면 소스 브랜치, 대상 원격 저장소, 대상 브랜치가 먼저 표시되고 확인한 뒤에 푸시됩니다. 처음 게시하는 브랜치는 원격 저장소를 선택할 수 있고, 게시에 성공하면 대상 브랜치를 upstream으로 설정할 수 있습니다. upstream이 없는 브랜치에는 `new`가 표시됩니다.

### 6.Ctrl+K로 세션 검색 열기

`Ctrl+K`(macOS에서는 `Command+K`)를 누르면 세션 검색이 열립니다. 열려 있을 때 다시 누르면 키워드가 선택되고, `Esc`로 닫습니다. `Ctrl+F`는 편집기의 파일 내 검색용으로 남겨 두었습니다.


## 사용성 개선

### 1.IM 설정 페이지와 카드 개선

1. "IM 원격 개입 및 알림"이 WeCom과 Feishu / Lark 두 개의 접을 수 있는 카드로 바뀌었고, 알림 유형은 "조치 필요"와 "실행 결과" 두 그룹으로 나뉩니다.
2. WeCom과 Feishu / Lark 카드는 데스크톱 언어를 따르며 7개 인터페이스 언어를 모두 지원합니다.
3. 처리가 끝난 WeCom 카드에 모든 질문과 사용자 지정 답변이 표시됩니다. WeCom의 여러 질문 단일 선택 카드는 최대 3개 질문까지이며, 이를 초과하는 요청은 데스크톱에서 처리하세요.

### 2.더 안정적인 세션

1. Agent 시작 단계에서 실패하면 자동 재시도가 정상적으로 다시 실행됩니다. 메시지가 이미 Agent에 전달된 뒤 실패한 턴은 중복 실행을 막기 위해 수동 복구로 전환됩니다. 시작 중에는 입력창에 "Agent 준비 중"이 표시됩니다.
2. 세션을 만들지 못하면 계속 로딩하지 않고 실패 이유를 바로 표시합니다.
3. 클라이언트가 비정상 종료된 뒤 남은 질문과 권한 요청은 무효가 되며, 답변하면 명확한 안내가 표시됩니다. 더 이상 제출 성공으로 표시되지 않습니다.
4. 세션을 이어갈 때 해당 세션의 원래 모델과 권한 모드를 그대로 사용합니다.
5. 회수된 Direct 세션에서 대화를 이어가면 Token 사용량이 중복 계산되던 문제를 수정했습니다.

### 3.더 자연스러운 스크롤

1. 입력창이 높아져도 메시지 목록이 맨 아래에 고정됩니다.
2. 기록을 읽는 동안 새 내용이 맨 아래로 끌어내리지 않습니다. 맨 위에서 계속 위로 스크롤하면 내용이 한 화면보다 짧아도 이전 기록을 불러옵니다.
3. 긴 임시 내용을 입력할 때 입력창의 스크롤 위치가 튀지 않습니다.

### 4.기타 개선

1. 입력창의 `/` 및 `@` 메뉴는 열 때마다 스킬과 역할을 다시 읽으므로, 새로 추가한 스킬을 재시작 없이 사용할 수 있습니다.
2. 대화에서 같은 이름의 첨부 파일이 이전 첨부 파일을 덮어쓰지 않습니다. 세션 데이터 디렉터리 계층이 너무 깊어 첨부 파일을 저장할 수 없으면 명확한 안내가 표시됩니다.
3. 대화의 로컬 이미지는 세션의 워크스페이스를 기준으로 해석됩니다. 내장 브라우저에서 로컬 HTML 링크를 열 때 쿼리 매개변수와 앵커가 유지됩니다.
4. Markdown 실시간 미리 보기가 패널 너비를 가득 채웁니다. 편집기 기본 글꼴 크기가 13px로 변경되었습니다.
5. 오른쪽 워크스페이스의 탭에 오류가 발생하면 해당 탭에만 "이 탭을 표시할 수 없습니다"가 표시되고 다른 탭에는 영향을 주지 않습니다.
6. `npx` 또는 `uvx`로 실행하는 MCP 서버는 첫 점검 시 종속성 다운로드가 끝날 때까지 최대 180초를 기다리므로, 다운로드 중에 실패로 판정되지 않습니다.
7. 시스템 언어가 중국어이면 지역이 아닌 간체·번체 문자 태그에 따라 인터페이스 언어를 선택합니다.
8. 대화 상자나 메뉴를 클릭한 뒤 툴팁이 저절로 나타나던 문제를 수정했습니다.
9. ACP Registry와 Agent 카탈로그를 업데이트했습니다.
