## 功能新增/调整

### 1.支持飞书远程干预

除了企业微信，现在也可以在飞书里处理任务卡住的权限、追问和人工检查，并接收 Run 和回合结束通知。

1. 打开「设置 → 通用 → IM 远程干预与通知」，展开「飞书」，点击「扫码接入」。
2. 确认所需权限后点击「同意并生成二维码」，用手机飞书扫码。可以选择已有的飞书应用，也可以新建应用。
3. 授权完成后，在飞书里给机器人发一条消息，完成一对一私聊绑定。
4. 任务需要你处理时，飞书会收到可操作卡片。卡片会显示编号、节点、任务和工作空间，可以同意或拒绝权限、回答追问（单选、多选、自定义答案和文本）、判定人工检查成功或失败。

提交后，卡片会保留你的答案并禁用控件；在桌面端或企业微信处理过的请求，飞书会显示处理来源。因停止、超时等原因结束的请求会显示「已取消」，不会显示为拒绝。提交处理较慢、最终未被接受时，机器人会另发一条消息说明原因。

在「配置管理」中可以重新绑定接收账号、更换飞书应用、重新授权或删除配置。

> [!NOTE]
> 一个机器人只连接一台设备。当前只支持一对一私聊，飞书卡片中的追问最多 5 题，超出的请求请在桌面端处理。读取姓名的权限是可选的，未授予时接收账号显示为「已绑定一对一私聊」。

> [!WARNING]
> 升级后 IM 数据会迁移到新格式，旧版本客户端无法再读取，降级需要先恢复备份。升级前已发出、仍未处理的企业微信卡片会失效，请在桌面端处理。

### 2.待发送队列支持立即发送和自动发送开关

Agent 回复时加入队列的消息，现在可以更灵活地控制发送时机。

1. 「立即发送」：直接发送某条待发送内容。当前有回复在进行时，会先确认是否停止当前回复；勾选「后续不再提示」后不再确认，可以在「设置 → 高级 → 待发送」中重新开启。
2. 「自动发送」开关：开启时，每轮回复结束后自动依次发送；关闭后内容只保留在队列中，由你逐条立即发送。
3. 停止会话或上一轮发送失败时，队列会显示「已暂停」及原因，点击「恢复」继续自动发送。
4. 在「更多操作」中可以清空待发送队列。

### 3.新增草稿箱

输入框工具栏新增「草稿箱」。点击「存入草稿箱」可以把当前输入内容暂存起来，之后再「取出到输入框」继续编辑。草稿只保存在当前会话，不会被自动发送，每个会话最多保留 20 条。

### 4.支持 Claude 原生子 Agent

使用 Claude ACP `0.90.0` 及以上版本时，Gold Band 会读取 Claude 上报的子 Agent 状态，准确显示运行中、等待交互、完成、中断和失败，不再因主回合结束就把子 Agent 显示为中断。

1. 有子 Agent 正在运行时，输入框上方会显示运行中子 Agent 摘要，点击可以在右侧工作区查看它的完整记录。
2. 主回合结束后，只要还有子 Agent 在后台运行或等待权限，输入框会保留「停止」按钮。
3. 会话出现后台工作后，Token 用量提示中会标注「不含后台唤醒的消耗」。

> [!IMPORTANT]
> Claude ACP 已升级到 `0.90.0`。版本过旧时会提示升级，Gold Band 不会自动修改你的安装配置。

### 5.推送前确认目标

在源码管理中推送分支时，会先显示源分支、目标远程仓库和目标分支，确认后才推送。首次发布的分支可以选择远程仓库，并在发布成功后设为上游。没有上游的分支会标记为 `new`。

### 6.使用 Ctrl+K 打开会话搜索

按 `Ctrl+K`（macOS 为 `Command+K`）打开会话搜索，已打开时再按会选中关键词，按 `Esc` 关闭。`Ctrl+F` 保留给编辑器的文件内搜索。


## 体验优化

### 1.IM 设置页与卡片优化

1. 「IM 远程干预与通知」改为企业微信、飞书两张可折叠卡片，通知类型分为「需要你处理」和「执行结果提醒」两组。
2. 企业微信和飞书卡片会跟随桌面端语言，支持全部七种界面语言。
3. 企业微信处理完成的卡片会完整显示所有问题和自定义答案。企业微信多题单选卡片最多 3 题，超出的请求请在桌面端处理。

### 2.会话更稳定

1. Agent 启动阶段失败时，自动重试可以正常重新执行；消息已经发给 Agent 后才失败的回合改为手动恢复，避免重复执行。启动期间输入框显示「正在准备 Agent」。
2. 会话没能建立时会直接显示失败原因，不再一直加载。
3. 客户端异常退出后遗留的提问和权限请求会失效，回答时会明确提示，不再显示提交成功。
4. 继续会话时沿用该会话原来的模型和权限模式。
5. 修复 Direct 会话被回收后继续对话时，Token 用量被重复计算的问题。

### 3.滚动更自然

1. 输入框变高时，消息列表保持贴在底部。
2. 向上阅读历史时，新内容不会把你拉回底部；在顶部继续向上滚动时可以加载更早的历史，内容不足一屏时也可以。
3. 输入较长草稿时，输入框的滚动位置不会跳动。

### 4.其他体验优化

1. 输入框的 `/` 和 `@` 菜单每次打开都会重新读取技能和角色，新增的技能无需重启即可使用。
2. 对话中同名的附件不再覆盖历史附件；会话数据目录层级过深、无法保存附件时会明确提示。
3. 对话中的本地图片按会话的工作区解析；内置浏览器打开本地 HTML 链接时保留查询参数和锚点。
4. Markdown 实时预览占满面板宽度；编辑器默认字号调整为 13px。
5. 右侧工作区某个标签页出错时，只在该标签页显示「此标签页无法显示」，不影响其他标签页。
6. 通过 `npx`、`uvx` 启动的 MCP 服务首次检测时会等待依赖下载完成，最长 180 秒，不再因下载中被判定失败。
7. 系统语言为中文时，按简体或繁体文字标记选择界面语言，不再受地区影响。
8. 修复点击弹窗、菜单后提示文字自动弹出的问题。
9. 更新 ACP Registry 与 Agent 目录。
