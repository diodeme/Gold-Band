## 功能新增/調整

### 1.支援飛書遠端干預

除了企業微信，現在也可以在飛書中處理任務卡住的權限、追問和人工檢查，並接收 Run 和回合結束通知。

1. 開啟「設定 → 一般 → IM 遠端干預與通知」，展開「飛書」，點擊「掃碼接入」。
2. 確認所需權限後點擊「同意並產生 QR Code」，用手機飛書掃碼。可以選擇既有的飛書應用，也可以新建應用。
3. 授權完成後，在飛書中傳一則訊息給機器人，完成一對一私聊綁定。
4. 任務需要你處理時，飛書會收到可操作卡片。卡片會顯示編號、節點、任務和工作空間，可以同意或拒絕權限、回答追問（單選、多選、自訂答案和文字）、判定人工檢查成功或失敗。

提交後，卡片會保留你的答案並停用控制項；在桌面端或企業微信處理過的請求，飛書會顯示處理來源。因停止、逾時等原因結束的請求會顯示「已取消」，不會顯示為拒絕。提交處理較慢、最終未被接受時，機器人會另傳一則訊息說明原因。

在「設定管理」中可以重新綁定接收帳號、更換飛書應用、重新授權或刪除設定。

> [!NOTE]
> 一個機器人只連接一台裝置。目前只支援一對一私聊，飛書卡片中的追問最多 5 題，超出的請求請在桌面端處理。讀取姓名的權限是選用的，未授予時接收帳號顯示為「已綁定一對一私聊」。

> [!WARNING]
> 升級後 IM 資料會遷移到新格式，舊版客戶端無法再讀取，降級需要先還原備份。升級前已發出、仍未處理的企業微信卡片會失效，請在桌面端處理。

### 2.待傳送佇列支援立即傳送和自動傳送開關

Agent 回覆時加入佇列的訊息，現在可以更靈活地控制傳送時機。

1. 「立即傳送」：直接傳送某條待傳送內容。目前有回覆正在進行時，會先確認是否停止目前回覆；勾選「之後不再提示」後不再確認，可以在「設定 → 進階 → 待傳送」中重新開啟。
2. 「自動傳送」開關：開啟時，每輪回覆結束後自動依序傳送；關閉後內容只保留在佇列中，由你逐條立即傳送。
3. 停止會話或上一輪傳送失敗時，佇列會顯示「已暫停」及原因，點擊「恢復」繼續自動傳送。
4. 在「更多操作」中可以清空待傳送佇列。

### 3.新增草稿箱

輸入框工具列新增「草稿箱」。點擊「存入草稿箱」可以把目前輸入內容暫存起來，之後再「取出到輸入框」繼續編輯。草稿只儲存在目前會話，不會被自動傳送，每個會話最多保留 20 條。

### 4.支援 Claude 原生子 Agent

使用 Claude ACP `0.90.0` 及以上版本時，Gold Band 會讀取 Claude 回報的子 Agent 狀態，準確顯示執行中、等待互動、完成、中斷和失敗，不再因主回合結束就把子 Agent 顯示為中斷。

1. 有子 Agent 正在執行時，輸入框上方會顯示執行中子 Agent 摘要，點擊可以在右側工作區查看它的完整記錄。
2. 主回合結束後，只要還有子 Agent 在背景執行或等待權限，輸入框會保留「停止」按鈕。
3. 會話出現背景工作後，Token 用量提示中會標註「不含背景喚醒的用量」。

> [!IMPORTANT]
> Claude ACP 已升級到 `0.90.0`。版本過舊時會提示升級，Gold Band 不會自動修改你的安裝設定。

### 5.推送前確認目標

在原始碼管理中推送分支時，會先顯示來源分支、目標遠端儲存庫和目標分支，確認後才推送。首次發布的分支可以選擇遠端儲存庫，並在發布成功後設為上游。沒有上游的分支會標記為 `new`。

### 6.使用 Ctrl+K 開啟會話搜尋

按 `Ctrl+K`（macOS 為 `Command+K`）開啟會話搜尋，已開啟時再按會選取關鍵字，按 `Esc` 關閉。`Ctrl+F` 保留給編輯器的檔案內搜尋。


## 體驗優化

### 1.IM 設定頁與卡片優化

1. 「IM 遠端干預與通知」改為企業微信、飛書兩張可摺疊卡片，通知類型分為「需要你處理」和「執行結果提醒」兩組。
2. 企業微信和飛書卡片會跟隨桌面端語言，支援全部七種介面語言。
3. 企業微信處理完成的卡片會完整顯示所有問題和自訂答案。企業微信多題單選卡片最多 3 題，超出的請求請在桌面端處理。

### 2.會話更穩定

1. Agent 啟動階段失敗時，自動重試可以正常重新執行；訊息已經傳給 Agent 後才失敗的回合改為手動恢復，避免重複執行。啟動期間輸入框顯示「正在準備 Agent」。
2. 會話未能建立時會直接顯示失敗原因，不再一直載入。
3. 客戶端異常退出後遺留的提問和權限請求會失效，回答時會明確提示，不再顯示提交成功。
4. 繼續會話時沿用該會話原本的模型和權限模式。
5. 修正 Direct 會話被回收後繼續對話時，Token 用量被重複計算的問題。

### 3.捲動更自然

1. 輸入框變高時，訊息列表保持貼在底部。
2. 向上閱讀歷史時，新內容不會把你拉回底部；在頂部繼續向上捲動時可以載入更早的歷史，內容不足一屏時也可以。
3. 輸入較長草稿時，輸入框的捲動位置不會跳動。

### 4.其他體驗優化

1. 輸入框的 `/` 和 `@` 選單每次開啟都會重新讀取技能和角色，新增的技能無需重啟即可使用。
2. 對話中同名的附件不再覆蓋歷史附件；會話資料目錄層級過深、無法儲存附件時會明確提示。
3. 對話中的本機圖片按會話的工作區解析；內建瀏覽器開啟本機 HTML 連結時保留查詢參數和錨點。
4. Markdown 即時預覽佔滿面板寬度；編輯器預設字級調整為 13px。
5. 右側工作區某個分頁出錯時，只在該分頁顯示「此分頁無法顯示」，不影響其他分頁。
6. 透過 `npx`、`uvx` 啟動的 MCP 服務首次檢測時會等待依賴下載完成，最長 180 秒，不再因下載中被判定失敗。
7. 系統語言為中文時，按簡體或繁體文字標記選擇介面語言，不再受地區影響。
8. 修正點擊對話框、選單後提示文字自動彈出的問題。
9. 更新 ACP Registry 與 Agent 目錄。
