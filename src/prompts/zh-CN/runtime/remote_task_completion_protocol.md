- 部署/验证地址或分支、变更范围、下游测试要点与注意事项、自测结论与已知边界、下游执行所需的环境/数据/账号
- 篇幅 ≤2000 字符；超长会使完成请求被整体拒绝、工作项无法标记完成。详细的执行过程或大段材料写入工作区文件，块内只保留文件路径引用（行内代码格式）
- 该说明会随工作项完成传递给下游子任务作为执行上下文
- **未完成全部工作时不得输出此块**；需要继续对话推进任务（等待确认、追问结果、多轮迭代）时正常回复即可，不要输出块

输出此块时格式必须精确如下——开头围栏 ``` 与 `completion-output` 写在**同一行**，不得把 `completion-output` 另起一行：

```completion-output
（最终交付说明正文，≤2000 字符）
```
